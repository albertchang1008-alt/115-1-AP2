# 教材目錄

每份教材使用獨立版本資料夾，例如 `chapter1-v1/index.html`，保留 CSS、JavaScript 與圖片的相對路徑。

GitHub Pages 發布後，將該 HTML 的 HTTPS 網址填入教師後台的 HTML 活動。此目錄中的檔案會公開發布，請勿放入名冊、學生紀錄或金鑰。

完整步驟見專案的 `docs/DEPLOYMENT.md`。

## 新增教材

最簡單的方式：在專案資料夾裡直接雙擊「`教材工作室.app`」，完全不會跳出終端機視窗，
背景啟動好之後直接跳出瀏覽器分頁（`http://127.0.0.1:5183/`）。照畫面上①匯入②稽核
③寫入教材目錄的順序操作，中途可預覽，貼錯或匯錯了可以在畫面下方的教材清單移除重來。
跑完仍要自己用 GitHub Desktop 確認變更並 push。

第一次雙擊「`教材工作室.app`」，macOS 可能會因為「無法驗證開發者」跳出警告——在
Finder 對它按住 Control 點一下（或按右鍵）、選「打開」，跳出的警告視窗再按一次「打開」，
之後就不會再跳出這個警告了。如果雙擊後瀏覽器分頁一直沒有跳出來，通常是這台電腦的
Node.js 安裝路徑比較特殊、App 找不到——這時候請改用下面的「`教材工作室.command`」，
它會開一個終端機視窗，把實際的錯誤訊息印出來方便排查。

也可以用「`教材工作室.command`」（雙擊會開一個終端機視窗執行，用完關掉視窗即可結束）或
自己開終端機下指令，效果都一樣：`npm run materials:studio`、`npm run materials:audit`
（單獨稽核既有教材）、`npm run materials:sync`（依 `shared/materials.ts` 單獨重新產生
下面的表格）。這幾種方式都只在本機執行，不會執行任何 git 指令。
