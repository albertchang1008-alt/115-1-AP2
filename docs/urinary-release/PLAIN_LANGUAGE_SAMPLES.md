## 例 1 kidney-anatomy-foundation-q01
**舊**：關於腎臟位置，哪一項正確？／A 位於後腹腔，右腎通常較低（正解）…
解析：腎臟在腹膜後方，右腎通常較左腎低；不要將畫面左右直接當成身體左右。

**新**：腎臟在身體的哪個位置？
- A 在腹膜的後面（後腹腔，靠背部），右腎通常比左腎低一點 ✔
- B 在腹膜腔裡面，右腎比左腎高
- C 在骨盆腔，左右一樣高
- D 在胸腔，左腎比右腎低
- 解析：腎臟貼著背部、躲在腹膜後面，所以叫「後腹腔器官」，而且右腎通常比左腎低一點。選「在腹膜腔裡面，右腎比左腎高」的同學把「腹膜後面」和「腹膜腔裡面」弄反了。
- ① 先想想：腎臟靠肚子前面，還是靠背後？
- ③ 答案是「在腹膜的後面，右腎通常比左腎低一點」，因為腎臟在腹膜後面，右腎比較低。
- ④ 腎躲腹膜後，右腎低一點。

## 例 2 urine-concentration-case-q05
**舊**：其他條件相同，ADH較少時，相較於ADH較多的情況，下列水回收與尿液變化何者合理？
解析：ADH 較少時末端通水減少，水回收較少，尿量較多且較稀；尿量與濃度是分開的量。

**新**：抗利尿激素（ADH）是叫腎臟「把水留下來」的激素。如果 ADH 變少，水和尿會怎麼變？
- A 留下的水變多，尿變少、變濃
- B 都不會改變
- C 留下的水變少，尿變多、變淡 ✔
- D 留下的水變少，尿變少、變濃
- 解析：ADH 會打開集尿管的水通道，讓水回到血液。ADH 變少，水通道變少，水留不住，就跟著尿排出去，所以尿變多、也變淡。選「留下的水變少，尿變少、變濃」的同學只想到「水變少」，忘了留不住的水是跑進尿裡。
- ① 先想想：ADH 少了，水是被留下，還是被排掉？
- ③ 答案是「留下的水變少，尿變多、變淡」，因為 ADH 少，水留不住，尿就多又淡。
- ④ ADH 少 → 水留不住 → 尿多又淡

## 例 3 fluid-compartments-case-q01
**舊**：【分母核對】資料先給體重，再註明採60%標準示例，第一步要算什麼？
**新**：題目告訴你一個人的體重，並說「身體的水約占體重 60%」。想算出細胞內、細胞外各有多少水，第一步要先算什麼？
- A 把整個體重都當成細胞內的水
- B 把血漿的比例當成全身水的比例
- C 先用體重算出全身總共有多少水 ✔
- D 直接把體重當成血漿的量
- 解析：要先知道「全身總共有多少水」（體重 × 60%），才能再把這些水分到細胞內和細胞外。例如 50 公斤的人，全身水約 50 × 60% = 30 公斤。
- ① 先想想：要分配水之前，需要先知道什麼？
- ③ 答案是「先用體重算出全身總共有多少水」，因為要先有全身總水量，才能往下分。
- ④ 先算總水量，再分內外。

## 例 4（化學，小六程度）acid-base-homeostasis-case-q04
**舊**：腎臟藉分泌H⁺與回收HCO₃⁻調整酸鹼時，下列物質移動方向何者正確？／A H⁺進入管液，HCO₃⁻回到血液（正解）
**新**：氫離子（H⁺）是讓血液變酸的小顆粒；碳酸氫根（HCO₃⁻）是會接住氫離子的小幫手。血液太酸時，腎臟會怎麼處理這兩樣東西？
- A 把氫離子送進尿裡排掉，把碳酸氫根留回血液 ✔
- B 把氫離子留回血液，把碳酸氫根送進尿裡
- C 兩樣都送進尿裡排掉
- D 兩樣都留回血液
- 解析：血液太酸，代表氫離子太多，所以腎臟把氫離子丟進尿裡；同時把碳酸氫根這個「小幫手」留下來，繼續接住血液裡的酸。選「兩樣都送進尿裡排掉」的同學把小幫手也一起丟掉了，這樣血液反而更難回到正常。
- ① 先想想：哪一樣讓血變酸？哪一樣是幫忙的？
- ③ 答案是「把氫離子送進尿裡排掉，把碳酸氫根留回血液」，因為要丟掉讓血變酸的氫離子，留下幫忙的碳酸氫根。
- ④ 酸丟尿裡，幫手留血裡。
