# 尿液通路與排尿控制｜學生腳本

## 開場
「尿在腎臟做好以後，要經過哪些管子、存在哪裡、又怎麼排出來？6 關之後你就知道。」〔開始〕

## 第 1 關｜輸尿管怎麼送尿？
- **先認識：** 輸尿管由腎盂通至膀胱，以蠕動送尿；斜行穿入膀胱壁的構造有助於防止逆流。
- **問題：**「尿從腎盂到膀胱，輸尿管靠什麼把尿往下送？」〔蠕動〕〔只靠重力〕
- **💡提示：**「輸尿管的管壁會一段一段地收縮。」
- **答錯：**「輸尿管以蠕動送尿。」
- **動作 ②：**「輸尿管斜斜地穿進膀胱壁，有什麼好處？」〔防止尿逆流〕〔讓尿流更快〕
  - 答錯回饋：「斜行穿入膀胱壁的構造有助於防止逆流。」

## 第 2 關｜輸尿管的三個窄處
- **先認識：** 輸尿管長約 25–30 cm。髂外動脈及靜脈，就是本圖中與輸尿管交叉的血管；課本列出的三處狹窄在腎盂交接、髂外動靜脈交叉、進入膀胱處。
- **問題：**「輸尿管有三個比較窄的地方。請在圖上點出來。」
- **💡提示：**「起點一個、中間跨過血管一個、終點一個。」
- **答對：**「三處分別在：腎盂交接處、和髂外動脈及靜脈交叉處、進入膀胱處。」
- **確認：**「輸尿管大約多長？」
  - A 25–30 cm（正）
  - B 3.8 cm
  - C 20 cm
  - 答錯回饋：B「3.8 cm 是女性尿道。」C「20 cm 是男性尿道。」

## 第 3 關｜膀胱三角與逼尿肌
- **先認識：** 膀胱三角由兩個輸尿管口和一個尿道內口圍成。逼尿肌是膀胱壁的平滑肌；內尿道括約肌也是平滑肌，外尿道括約肌是骨骼肌，能由意識控制。
- **問題：**「膀胱三角由哪三個開口圍成？請在圖上點出來。」
- **動作：** 點兩個輸尿管口，再點尿道內口。
- **💡提示：**「兩個開口進來、一個開口出去。」
- **動作 ②：**「膀胱壁負責把尿擠出去的肌肉叫？」〔逼尿肌〕〔外括約肌〕
- **確認：**「哪一個是骨骼肌、可以自己控制？」
  - A 外尿道括約肌（正）
  - B 逼尿肌
  - C 內尿道括約肌
  - 答錯回饋：「逼尿肌和內括約肌都是平滑肌；外括約肌是骨骼肌。」

## 第 4 關｜男生和女生的尿道
- **先認識：** 女性尿道約 3.8 cm，男性約 20 cm。男性尿道由內到外依序是前列腺部、膜部、陰莖部；膜部是這三段中位於前列腺部與陰莖部之間的一段。陰部神經是控制外尿道括約肌的神經，該肌肉屬骨骼肌。
- **問題：**「請把 3.8 cm 和 20 cm 分別放到女性尿道、男性尿道。」
- **💡提示：**「男性尿道要穿過陰莖，比較長。」
- **動作 ②：**「請從膀胱往外，依序點出男性尿道三段：前列腺部 → 膜部 → 陰莖部。」
- **確認：**「外尿道括約肌由哪條神經控制？」
  - A 陰部神經（正）
  - B 交感神經
  - C 骨盆副交感神經
  - 答錯回饋：「外括約肌屬骨骼肌，由陰部神經控制。」

## 第 5 關｜什麼時候想尿尿？怎麼排出來？
- **先認識：** 骨盆副交感神經（S2–S4）促使逼尿肌收縮、內括約肌鬆弛；儲尿時交感神經促使相反反應。陰部神經控制外尿道括約肌，這是能由意識控制的出口肌肉。
- **動作 ①：** 拖動膀胱尿量滑桿。超過約 300 mL 時，畫面出現「想尿尿了」。
- **問題：**「要排尿時，逼尿肌和內括約肌各會怎樣？」
  - 逼尿肌〔收縮〕〔放鬆〕
  - 內括約肌〔放鬆〕〔收縮〕
- **💡提示：**「要把尿擠出去：袋子要擠緊，出口要打開。」※
- **答對：**「排尿反射讓逼尿肌收縮、內括約肌鬆弛。」
- **確認：**「排尿時，讓逼尿肌收縮的是？」
  - A 骨盆副交感神經（S2–S4）（正）
  - B 交感神經
  - C 陰部神經
  - 答錯回饋：「儲尿時交感神經造成相反的反應；陰部神經控制外括約肌。」

## 第 6 關｜正常的尿
- **先認識：** 健康成人每日尿量約 1–2 L，水分約佔 95%。剛排出的正常尿呈稻草色、透明；放久後可因細菌作用變混濁。
- **問題：**「健康成人一天大約尿多少？尿裡大部分是什麼？」
  - 〔約 1–2 L，水約 95%〕
  - 〔約 5 L，水約 50%〕
- **💡提示：**「尿裡幾乎都是水。」
- **確認：**「剛排出的正常尿液看起來？」
  - A 稻草色、透明（正）
  - B 一定是混濁的
  - C 紅色
  - 答錯回饋：「剛排出時是透明的，放久了可能因細菌作用變混濁。」

## 結尾
1. 「尿的路線？」〔腎盂→輸尿管→膀胱→尿道〕〔腎盂→尿道→膀胱→輸尿管〕
2. 「排尿時？」〔逼尿肌收縮、內括約肌放鬆〕〔逼尿肌放鬆、內括約肌收縮〕
3. 「可以自己控制的是？」〔外括約肌〕〔逼尿肌〕

- **結語：**「輸尿管蠕動把尿送到膀胱；膀胱滿了引起排尿反射，逼尿肌收縮、內括約肌放鬆；外括約肌可以由我們自己控制。」
- **過渡頁空格：**「尿液的通路和排尿」
