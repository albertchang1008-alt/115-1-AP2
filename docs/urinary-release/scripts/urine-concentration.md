# 逆流機制與尿液濃縮｜學生腳本

## 開場
「天氣熱、喝水少時，尿會變黃又少；喝很多水時，尿又多又淡。※ 腎臟怎麼做到的？6 關之後你就知道。」〔開始〕

## 第 1 關｜做出濃尿需要什麼？
- **先認識：** 滲透＝水會往溶質（鹽、尿素等）比較多的地方移動。髓質梯度＝腎髓質越深越濃。※ ADH＝抗利尿激素，可增加集尿管對水的通透性。濃尿可達 1200 mOsm/L（數字越大代表越濃），約為血漿的四倍；mOsm/L 是本關比較滲透濃度的單位。
- **問題：**「要做出很濃的尿，需要哪兩個條件同時成立？請從四張卡選兩張。」
  - 〔髓質很濃〕
  - 〔集尿管讓水通過（有 ADH）〕
  - 〔多喝水〕
  - 〔過濾變多〕
- **💡提示：**「水要被『吸』出去：外面要夠濃，管壁也要讓水過。」
- **答對：**「濃縮需要髓質的高滲透梯度，加上集尿管可以調節水的通透性；ADH 增加水回收，形成濃尿。」
- **確認：**「課本說濃尿最高可以達到？」
  - A 1200 mOsm/L，約血漿的四倍（正）
  - B 跟血漿一樣
  - C 比血漿稀
  - 答錯回饋：「課本：濃尿可達 1200 mOsm/L，約為血漿的四倍。」

## 第 2 關｜往下走的時候
- **先認識：** 亨利氏環是腎小管向下延伸再折返的一段。※ 下降枝可通水、對溶質通透差；水移出後管液會變濃。
- **問題：**「亨利氏環的下降枝會讓水通過。管液往下流時，會變濃還是變稀？」
- **動作 ①：** 點下降枝，水的箭頭往外移出。
- **動作 ②：**〔變濃〕〔變稀〕
- **💡提示：**「水走了，管液裡的水變少，會變濃還是變稀？」
- **答錯：**「下降枝讓水出去，管液變濃。」
- **確認：**「下降枝可以讓什麼通過？」
  - A 水可以通過（正）
  - B 鹽可以通過，水不行
  - C 兩者都不行
  - 答錯回饋：「下降枝通水，但對溶質的通透性差。」

## 第 3 關｜往上走的時候
- **問題：**「上升枝不讓水通過，但會把鹽（NaCl）送出去。管液會變稀還是變濃？」
- **動作 ①：** 點上升枝，鹽的箭頭往外移出。
- **動作 ②：**〔變稀〕〔變濃〕
- **💡提示：**「鹽走了，水留下來。」
- **補充（答對後顯示）：**「上升枝一次帶走一個 Na⁺、一個 K⁺、兩個 Cl⁻。」
- **確認：**「上升枝把鹽送出去，對髓質有什麼幫助？」
  - A 讓髓質維持很濃（正）
  - B 讓髓質變稀
  - C 讓上升枝的水流出去
  - 答錯回饋：「亨利氏環的逆流增強作用，負責維持髓質的高張環境。」

## 第 4 關｜直血管為什麼彎成 U 形？※
- **先認識：** 亨利氏環的逆流增強裝置維持髓質高張環境；直血管以緩慢的逆流交換減少髓質溶質流失。「逆流」先理解成液體沿相反方向流動。
- **問題：**「直血管彎成 U 形，而且血流得很慢。這樣有什麼好處？」〔減少髓質的溶質被血液帶走〕〔把尿運出去〕※
- **💡提示：**「如果血液又快又直地穿過去，髓質的鹽會怎樣？」※
- **答錯：**「直血管緩慢地逆流交換，可以減少髓質溶質流失。」
- **確認：**「直血管扮演的角色叫？」
  - A 逆流交換（正）
  - B 逆流增強
  - C 過濾
  - 答錯回饋：「逆流增強是亨利氏環；直血管負責逆流交換。」

## 第 5 關｜ADH 打開水的通道
- **先認識：** ADH 是抗利尿激素。水不足時，腦下垂體後葉釋放 ADH；它增加水通道，讓水沿髓質梯度再吸收，形成濃尿。
- **問題：**「身體缺水時會釋放 ADH。請打開 ADH 開關，看看集尿管多了什麼？」〔水通道〕〔鈉通道〕
- **💡提示：**「ADH 叫『抗利尿』激素，作用是讓尿變少、水留在身體。」
- **答對：**「ADH 增加水通道，水沿髓質梯度被回收，形成濃尿。」
- **確認：**「ADH 從哪裡釋放？」
  - A 腦下垂體後葉（正）
  - B 腎臟
  - C 膀胱
  - 答錯回饋：「水不足時，由腦下垂體後葉釋放 ADH。」

## 第 6 關｜有 ADH 和沒有 ADH
- **先認識：** 這裡把髓質高滲透梯度維持相同，只比較末端能不能讓水通過。ADH 直接調整水的通透性；醛固酮主要促進鈉再吸收，水可隨滲透作用回收，兩者保水方式不同。
- **問題：**「請把『濃尿』『稀尿』分到〔有 ADH〕和〔沒有 ADH〕。」
- **💡提示：**「有 ADH，水被拿回去。」
- **確認：**「ADH 和醛固酮都能保水，方法哪裡不同？」
  - A ADH 直接讓水通過；醛固酮主要是回收鈉（正）
  - B 兩個都只回收鈉
  - C 兩個都直接打開水通道
  - 答錯回饋：「ADH 直接調整水的通透性；醛固酮主要促進鈉再吸收。」

## 結尾
1. 「下降枝？」〔水出去、管液變濃〕〔鹽出去、管液變稀〕
2. 「上升枝？」〔鹽出去、管液變稀〕〔水出去、管液變濃〕
3. 「有 ADH 時？」〔集尿管回收水、形成濃尿〕〔水排出、形成稀尿〕

- **結語：**「亨利氏環讓髓質變濃，直血管保住這個梯度，ADH 打開集尿管的水通道，水被吸回，尿就變濃。」
- **過渡頁空格：**「腎臟怎麼把尿變濃」
