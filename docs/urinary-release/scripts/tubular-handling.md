# 腎小管再吸收、分泌與排泄｜學生腳本

## 開場
「濾出來的液體很多，但大部分會被拿回去。腎小管會把有用的東西還給血液，也會把多的東西送進尿裡。6 關之後，你會算出尿裡最後剩多少。」〔開始〕

## 第 1 關｜三種移動，往哪裡走？
- **先認識：** 管液＝腎小管裡的液體，之後會變成尿。過濾把物質由血液移入鮑氏囊；再吸收把管液中的物質送回血液；分泌把血液中的物質送入管液。
- **問題：**「請把『過濾』『再吸收』『分泌』三個箭頭放到圖上，並指向正確方向。」
- **💡提示：**「『再吸收』是拿回來，回到血液。」
- **答對：**「過濾：血液→鮑氏囊；再吸收：管液→血液；分泌：血液→管液。」
- **確認：**「分泌是把物質從哪裡送到哪裡？」
  - A 血液→管液（正）
  - B 管液→血液
  - C 鮑氏囊→血液
  - 答錯回饋：「管液→血液是再吸收。」

## 第 2 關｜尿裡最後剩多少？
- **問題：**「排泄量＝過濾量 □ 再吸收量 □ 分泌量。請在兩個框裡填上＋或－。」
- **💡提示：**「拿回去的要扣掉，額外送進來的要加上。」
- **答對：**「排泄量＝過濾量－再吸收量＋分泌量。」
- **確認：**「葡萄糖正常會全部被再吸收，所以尿中的葡萄糖會？」
  - A 幾乎沒有（正）
  - B 等於過濾量
  - C 比過濾量更多
  - 答錯回饋：「全部回收，尿中就幾乎沒有。」

## 第 3 關｜近曲小管拿回什麼？
- **先認識：** 葡萄糖、胺基酸正常可全部回收；尿素部分回收，肌酸酐不被再吸收。尿素和肌酸酐是代謝廢物，肌酸酐與肌肉代謝有關。水主要依滲透作用回收，也就是水移向溶質較多的地方。
- **問題：**「請把葡萄糖、胺基酸、尿素、肌酸酐，分到〔正常全部回收〕〔部分回收〕〔不回收〕。」
- **💡提示：**「葡萄糖、胺基酸這些營養，正常會全部拿回；廢物不一定。」※
- **答對：**「葡萄糖、胺基酸正常全部回收；尿素部分回收；肌酸酐不被再吸收。」
- **確認：**「水主要靠什麼被回收？」
  - A 滲透作用（正）
  - B 分泌
  - C 過濾
  - 答錯回饋：「水主要依滲透作用回收。」

## 第 4 關｜回收能力有上限
- **先認識：** 最大轉運量＝回收葡萄糖的能力上限，課本為 375 mg/min。
- **問題：**「如果過濾出來的葡萄糖越來越多，超過腎小管回收的上限，會發生什麼事？」
- **動作 ①：** 拖動「過濾出來的葡萄糖」滑桿：沒超過 375 時全部回收；超過後，尿中出現葡萄糖。
- **💡提示：**「搬運工一次只能搬那麼多，多出來的就留下了。」※
- **動作 ②：**「過濾出來的葡萄糖超過 375 mg/min，會怎樣？」〔出現糖尿〕〔還是全部回收〕
  - 答錯回饋：「過濾負荷超過回收能力時，就會出現糖尿。」

## 第 5 關｜鉀的調節
- **先認識：** K⁺ 是鉀離子。鉀在小管前段大量回收，最後尿鉀仍受後段分泌調整；遠曲小管與集尿管可把鉀分泌到管液。醛固酮是調節鈉、鉀處理的激素，促進鈉再吸收，同時增加鉀分泌。
- **問題：**「血鉀太高時，腎臟在哪兩段把 K⁺ 送進尿裡？請在圖上點出來。」〔遠曲小管〕〔集尿管〕
- **💡提示：**「沿圖上的管液流向，回看先認識中『最後調整』的功能，再把它對到兩個管段。」
- **動作 ②：**「醛固酮會讓 K⁺ 的分泌？」〔增加〕〔減少〕
  - 答錯回饋：「醛固酮促進遠端鈉再吸收，同時增加鉀分泌。」
- **確認：**「最後尿裡的鉀，主要由什麼決定？」
  - A 後段的分泌調整（正）
  - B 只看一開始過濾多少
  - 答錯回饋：「前段大量回收鉀，最後的尿鉀仍受後段分泌調整。」

## 第 6 關｜尿比較濃，就一定是分泌嗎？
- **先認識：** 濃度與排出的物質量不同；水回收也會使尿液變濃，不一定是另加物質進去。GFR＝腎絲球過濾率，指每分鐘形成的濾液體積；清除率是每分鐘排除某物質所相當的血漿體積，兩者可用 mL/min 比較。物質排泄量則是物質量／時間。
- **問題：**「某物質在尿中的濃度比血漿高，表示它一定被分泌嗎？」〔不一定〕〔一定〕
- **💡提示：**「如果水被拿回去很多，剩下的尿會變怎樣？」
- **答錯：**「水被回收也會讓尿變濃，濃度高不一定是分泌。」
- **確認：**「要拿來和 GFR（mL/min）比大小的，應該是？」
  - A 清除率（正）
  - B 排泄量
  - C 尿中濃度
  - 答錯回饋：「清除率和 GFR 都用 mL/min，才能比較；排泄量是物質量／時間。」

## 結尾
1. 「再吸收的方向？」〔管液→血液〕〔血液→管液〕
2. 「排泄量＝？」〔過濾－再吸收＋分泌〕〔過濾＋再吸收－分泌〕
3. 「出現糖尿是因為？」〔超過最大轉運量〕〔腎臟分泌葡萄糖〕

- **結語：**「腎小管把有用的東西拿回血液、把多的送進尿；尿裡剩多少，要把過濾、再吸收、分泌三者一起算。」
- **過渡頁空格：**「腎小管怎麼回收和分泌」
