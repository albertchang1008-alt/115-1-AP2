# 腎元、腎血流與近腎絲球器｜學生腳本

## 開場
「腎臟裡有很多製造尿液的小單位，叫做『腎元』。※ 血液怎麼流進腎臟？腎臟又怎麼知道血壓變低了？6 關之後你就知道。」〔開始〕

## 第 1 關｜腎元由哪兩部分組成？
- **先認識：** 腎元＝腎臟製造尿液的基本單位。※ 腎元由腎小體與腎小管構成；腎小體包括腎絲球與鮑氏囊。腎盂、腎盞是收集尿液的構造。
- **問題：**「請把『腎小體』和『腎小管』放到腎元圖上。」
- **💡提示：**「腎小體是圓球那一端，腎小管是後面長長的管子。」※
- **答對：**「腎元由腎小體和腎小管組成。」
- **動作 ②：**「腎小體裡有哪兩個構造？」〔腎絲球＋鮑氏囊〕〔腎盂＋腎盞〕
  - 答錯回饋：「腎盂、腎盞是收集尿的地方；腎小體由腎絲球和鮑氏囊組成。」

## 第 2 關｜兩種腎元，哪裡不一樣？
- **先認識：** 亨利氏環＝腎小管往下延伸、再折返的一段。※ 皮質腎元佔大多數；近髓質腎元靠近皮質與髓質交界。皮質腎元的環較短，近髓質腎元的環較長、深入髓質；兩型腎小體都在皮質。
- **問題：**「圖上有兩個腎元。哪一個的亨利氏環比較長、伸到髓質深處？請點它，並選名字。」〔近髓質腎元〕〔皮質腎元〕
- **💡提示：**「『近髓質』表示位置靠近皮質和髓質的交界。」
- **答對：**「近髓質腎元的環長、深入髓質，配合直血管幫忙濃縮尿液。」
- **確認：**「下面哪一句是對的？」
  - A 大多數腎元是皮質腎元（正）
  - B 近髓質腎元整個都在髓質裡
  - C 兩種腎元的腎小體都在髓質
  - 答錯回饋：B「近髓質是指靠近交界，它的腎小體仍在皮質。」C「兩種腎元的腎小體都在皮質。」

## 第 3 關｜腎小管每一段的細胞長得不一樣
- **先認識：** 刷狀緣＝細胞表面密密麻麻的小突起（微絨毛）。※ 近曲小管是有刷狀緣的立方上皮；遠曲小管也是立方上皮，但沒有明顯微絨毛。亨利氏環薄段是扁平上皮。
- **問題：**「哪一段小管的細胞有刷狀緣？請在圖上點出來。」
- **💡提示：**「遠曲小管沒有明顯的微絨毛。」
- **答對：**「近曲小管是有刷狀緣的立方上皮。」
- **答錯：**「遠曲小管是立方上皮，但沒有明顯的微絨毛。」
- **動作 ②：**「亨利氏環的薄段，細胞是什麼形狀？」〔扁平〕〔立方〕
  - 答錯回饋：「薄段是扁平上皮。」

## 第 4 關｜血液進腎臟後怎麼走？
- **問題：**「血液從大血管一路分支進來。請依序點出接下來的四段：入球小動脈 → 腎絲球 → 出球小動脈 → 管周微血管。」
- **💡提示：**「『入』是進來，『出』是出去。」
- **答錯：**「腎絲球前面是入球小動脈，後面是出球小動脈。」
- **答對：**「兩套微血管依序工作：腎絲球負責過濾，管周微血管負責和小管交換。」
- **確認：**「腎絲球前後兩端是哪一種血管？」
  - A 小動脈（正）
  - B 靜脈
  - C 微血管
  - 答錯回饋：「腎絲球的前後都是小動脈。」

## 第 5 關｜腎臟怎麼知道血壓變低？
- **先認識：** 管液是腎小管裡的液體。近腎絲球細胞在入球小動脈壁上，感受壓力並分泌腎素；緻密斑在遠曲小管，感受管液的鈉變化。血壓低或管液鈉低可促進腎素分泌。
- **問題：**「請在圖上找出兩種『感測器』：一種感受血壓，一種感受管液裡的鈉。」
- **動作：** 點近腎絲球細胞，出現「在入球小動脈壁上，感受壓力、分泌腎素」；點緻密斑，出現「在遠曲小管，感受管液的鈉」。
- **💡提示：**「一個在血管壁上，一個在小管上。」
- **動作 ②：**「血壓變低時，近腎絲球細胞會分泌什麼？」〔腎素〕〔ADH〕
  - 答錯回饋：「血壓低或管液鈉低時，會促進腎素分泌。」

## 第 6 關｜腎血流和腎血漿流量
- **先認識：** 血漿是血液裡的液體部分。※ 腎血流計整體血流，腎血漿流量只計其中的血漿部分。
- **問題：**「一管血分成血球和血漿兩層。腎血漿流量只算哪一部分？請點它。」〔血漿〕
- **💡提示：**「先辨認圖上兩層各代表什麼，再想這個流量要把整管都算進去，還是只算其中一部分；回看先認識。」
- **答對：**「課本腎血流每分鐘約 1200 mL，約占心輸出量的四分之一；腎血漿流量只算其中的血漿部分。」
- **確認：**「下面哪一句是對的？」
  - A 腎血流約 1200 mL/min，約占心輸出量四分之一（正）
  - B 腎血流就等於全部的心輸出量
  - C 腎血流和腎血漿流量是同一個數字
  - 答錯回饋：B「腎血流約占四分之一。」C「血漿流量只算血漿那一部分。」

## 結尾
1. 「腎元由什麼組成？」〔腎小體＋腎小管〕〔腎盂＋輸尿管〕
2. 「血液經過腎絲球的順序？」〔入球→腎絲球→出球〕〔出球→腎絲球→入球〕
3. 「血壓變低時？」〔近腎絲球細胞分泌腎素〕〔緻密斑分泌 ADH〕

- **結語：**「腎元由腎小體和腎小管組成；血液經入球小動脈、腎絲球、出球小動脈；近腎絲球器感受血壓與鈉，並分泌腎素。」
- **過渡頁空格：**「腎元和腎臟的血流」
