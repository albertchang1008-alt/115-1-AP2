# 水分收支與鈉水調節｜學生腳本

## 開場
「身體每天都在喝水、也在流失水。缺水或血壓變低時，身體怎麼把水和鈉留住？太多時又怎麼排掉？6 關之後你就知道。」〔開始〕

## 第 1 關｜水從哪裡進來？
- **先認識：** 代謝水＝身體分解養分時自己產生的水。※ 課本每日攝取的平衡例為飲入液體 1500 mL、食物含水 800 mL、代謝水 200 mL，合計約 2500 mL。
- **問題：**「請從六張卡中，選出水『進入』身體的三個來源。」
  - 〔喝下的液體〕〔食物裡的水〕〔代謝水〕〔尿液〕〔呼氣〕〔流汗〕
- **💡提示：**「選『進來』的，不要選『出去』的。」
- **確認：**「課本說，平均每天總共攝取多少水？」
  - A 約 2500 mL（正）
  - B 約 250 mL
  - C 約 25 L
  - 答錯回饋：「課本平均每日總攝取約 2500 mL。」

## 第 2 關｜水從哪裡出去？
- **先認識：** 無知覺蒸散＝在不知不覺中，從皮膚蒸發掉的水。※ 課本將皮膚無知覺蒸散和流汗分開列，肺另列呼氣失水；正常時液體的攝取與排出維持平衡。
- **問題：**「請把四條排出途徑，放到圖上對應的器官：尿液→腎、呼氣→肺、蒸散與流汗→皮膚、糞便→腸。」
- **💡提示：**「呼氣也會帶走水氣，冬天對著窗戶哈氣就看得到。」※
- **確認：**「正常時，水的攝取和排出是什麼關係？」
  - A 維持平衡（正）
  - B 排出永遠比攝取多
  - C 兩者沒有關係
  - 答錯回饋：「正常時，液體的攝取和排出維持平衡。」

## 第 3 關｜缺水時怎麼辦？
- **先認識：** ADH＝抗利尿激素，水不足時由腦下垂體後葉釋放，可增加保水；口渴增加水的攝取。鈉的總量是有多少鈉，鈉濃度則是鈉量與水量的比例，兩者不能當同一件事。
- **問題：**「身體缺水時，有兩個方法補救。請選出這兩個。」〔口渴，多喝水〕〔ADH，讓腎多保留水〕〔多流汗〕
- **💡提示：**「一個是讓水『多進來』，一個是讓水『少出去』。」
- **答對：**「口渴增加攝取，ADH 增加保水，兩者互相配合。」
- **確認：**「『鈉的總量改變』和『鈉的濃度改變』，是同一件事嗎？」
  - A 不是（正）
  - B 是
  - 答錯回饋：「鈉的總量和鈉的濃度要分開看，不能當成同一件事。」

## 第 4 關｜血壓變低時的連鎖反應（RAAS）
- **先認識：** RAAS＝腎素—血管收縮素—醛固酮系統，是一條調節血壓的連鎖反應。近腎絲球細胞在入球小動脈壁上；血壓下降時釋放腎素，啟動讓血管收縮、留住鈉和水的反應，使血壓回升。
- **問題：**「血壓下降時，腎臟會啟動一連串反應。第一步，是哪個細胞釋放什麼？請在圖上點出來。」
- **動作 ①：** 點近腎絲球細胞，出現〔腎素〕。
- **💡提示：**「上一份教材（腎元）講過：入球小動脈壁上的細胞。」
- **動作 ②：**「這一串反應最後讓身體？」〔血管收縮、留住鈉和水，血壓回升〕〔血管放鬆、排掉鈉和水〕
  - 答錯回饋：「失血、脫水讓血壓下降時，這條鏈讓血管收縮、留住鈉和水，把血壓撐回來。」

## 第 5 關｜醛固酮和 ADH，保水的方法不同
- **先認識：** 醛固酮是調節鈉、鉀處理的激素，促進遠端鈉再吸收，同時增加鉀分泌；分泌是從血液送入管液。ADH 直接增加遠端與集尿管對水的通透性。
- **問題：**「請把兩個激素配到它的做法。」
  - 醛固酮 →「讓腎多回收鈉，水跟著滲透回收」
  - ADH →「直接讓集尿管讓水通過」
- **💡提示：**「名字裡有『抗利尿』的，是直接管水。」
- **確認：**「醛固酮讓鈉回收增加時，鉀會？」
  - A 分泌增加（正）
  - B 回收增加
  - C 不變
  - 答錯回饋：「醛固酮促進遠端鈉再吸收，同時增加鉀分泌。」

## 第 6 關｜太多時怎麼排掉？
- **先認識：** ANP（心房利鈉尿肽）＝心房分泌的激素，會讓鈉排出。ANP 也可抑制 ADH，使水分排泄增加、體內液體量減少。課本區分：醛固酮主要調節鈉含量與體液容積，ADH 主要調節水與體液濃度。
- **動作 ①：** 打開 ANP 開關，觀察腎臟的變化。
- **問題：**「ANP 作用後，身體會？」〔排出更多鈉，體液量減少〕〔留住更多鈉〕
- **💡提示：**「看名字：『利鈉尿』。」
- **答對：**「ANP 增加腎絲球過濾，並促進鈉排泄。」
- **動作 ②：**「誰主要管體液的『量』，誰主要管『濃度』？」把醛固酮、ADH 放到〔鈉含量與體液容積〕〔水與體液濃度〕。
  - 答錯回饋：「課本區分：醛固酮調節鈉含量與體液容積，ADH 調節水與體液濃度。」

## 結尾
1. 「缺水時？」〔口渴＋ADH 保水〕〔多排尿〕
2. 「血壓變低時？」〔腎素啟動 RAAS，留鈉留水〕〔ANP 排鈉〕
3. 「醛固酮主要管？」〔鈉與體液容積〕〔體液濃度〕

- **結語：**「水的進出要平衡；缺水靠口渴和 ADH，血壓低靠 RAAS 留住鈉和水，太多時 ANP 幫忙排鈉。」
- **過渡頁空格：**「身體怎麼調節水和鈉」
