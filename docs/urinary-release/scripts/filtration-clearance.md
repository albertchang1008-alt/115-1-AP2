# 腎絲球過濾與清除率｜學生腳本

## 開場
「腎臟像一個濾網：把血液裡的水和小東西濾出來，大的留在血液裡。※ 6 關之後，你會知道什麼過得去、什麼過不去，也會知道醫護人員怎麼用『清除率』看腎臟的工作量。」〔開始〕

## 第 1 關｜過濾往哪個方向走？
- **先認識：** 鮑氏囊＝包住腎絲球、接住濾出液體的囊。腎小體由腎絲球與鮑氏囊組成，位於皮質；血液中的水和可以通過的溶質經過濾膜進入鮑氏囊。
- **問題：**「過濾時，水和小分子是從腎絲球（血液）流到鮑氏囊，還是反過來？請點箭頭，讓它指向正確方向。」
- **💡提示：**「濾出來的液體最後會變成尿。」
- **答對：**「血液裡的水和可以通過的溶質，經過濾膜進入鮑氏囊。」
- **確認：**「濾液在哪裡形成？」
  - A 皮質的腎小體（正）
  - B 輸尿管
  - C 腎盂
  - 答錯回饋：「形成濾液的位置是皮質的腎小體，不是輸尿管或腎盂。」

## 第 2 關｜過濾膜有三層
- **先認識：** 過濾膜從血液側依序是微血管內皮、基底膜、鮑氏囊臟層足細胞。白話認圖：內皮是血管的內襯，基底膜在中間；足細胞是囊靠腎絲球那側（臟層）的細胞，壁層是囊的外壁。※ 鮑氏囊壁層不構成三層過濾膜。
- **問題：**「請從血液那一側開始，依序點出過濾膜的三層。」
- **動作：** 微血管內皮 → 基底膜 → 足細胞（鮑氏囊臟層）
- **💡提示：**「從血管自己的牆壁開始。」
- **答錯：**「依序是：微血管內皮、基底膜、鮑氏囊臟層足細胞。」
- **確認：**「下面哪一個『不是』過濾膜的一層？」
  - A 鮑氏囊壁層（正）
  - B 基底膜
  - C 足細胞
  - 答錯回饋：「鮑氏囊壁層不屬於三層過濾膜。」

## 第 3 關｜什麼過得去，什麼過不去？
- **先認識：** 白蛋白是本關要辨認的血漿蛋白；正常濾液不含血球及白蛋白，水、葡萄糖、胺基酸與小分子溶質可以過濾。血漿本來就不包含血球，比較血漿和濾液時，要看蛋白質的差別。
- **問題：**「請把水、葡萄糖、胺基酸、白蛋白、紅血球，分到〔過得去〕或〔過不去〕。」
- **💡提示：**「太大的東西過不去。」
- **答對：**「葡萄糖、胺基酸和小分子可以過濾；正常濾液沒有血球，也沒有白蛋白。」
- **確認：**「血漿和濾液最主要的差別是？」
  - A 蛋白質（正）
  - B 血球
  - C 水
  - 答錯回饋：B「血漿本來就沒有血球，所以不能拿血球來比。」C「水可以自由過濾。」

## 第 4 關｜哪個力量推，哪個力量擋？
- **先認識：** 腎絲球（微血管內）的靜水壓，像水管裡往外推的水壓。※ 這股力量把水推進鮑氏囊；囊內壓是囊內液體對抗過濾的壓力。血漿膠體壓可想成血漿蛋白質把水拉回血管的力量，會對抗過濾。
- **問題：**「請把三個壓力卡放到〔推進鮑氏囊〕或〔對抗過濾〕：腎絲球（微血管內）的靜水壓、囊內壓、血漿膠體壓。」
- **💡提示：**「先找每股力量從哪一側作用，再對照先認識，想它把水推進囊內，還是留在血液。」
- **答對：**「腎絲球（微血管內）的靜水壓促進過濾；囊內壓和血漿膠體壓對抗過濾。」
- **答錯（腎絲球壓力卡）：**「腎絲球（微血管內）的靜水壓促進過濾。」
- **答錯（囊內壓卡）：**「囊內壓對抗過濾。」
- **答錯（血漿膠體壓卡）：**「血漿膠體壓對抗過濾。」

## 第 5 關｜清除率公式
- **先認識：** 清除率 C＝U×V／P，代表每分鐘排除某物質所相當的血漿體積。U 是尿中濃度，V 是每分鐘尿量，P 是血漿濃度；清除率不是每分鐘尿量本身。
- **問題：**「請把『尿中濃度』『每分鐘尿量』『血漿濃度』放到 U、V、P。」
- **💡提示：**「U 和 V 都跟尿有關，P 是血漿。」
- **答對：**「U 是尿中濃度，V 是每分鐘尿量，P 是血漿濃度。」
- **確認：**「清除率的意思是？」
  - A 每分鐘排除某物質所相當的血漿體積（正）
  - B 每分鐘尿量
  - C 血漿裡這個物質的濃度
  - 答錯回饋：「清除率代表『每分鐘清掉多少體積的血漿』裡的這個物質。」

## 第 6 關｜菊糖、肌酸酐、PAH
- **先認識：** GFR＝腎絲球過濾率，指每分鐘形成的濾液體積。菊糖在這裡是用來當過濾指標的物質，只過濾、不再吸收也不分泌；PAH 是兼具過濾與分泌、可用來估腎血漿流量的物質。肌酸酐與肌肉代謝有關，不被再吸收，但有少量分泌。
- **問題：**「三種物質在腎臟的遭遇不同。請把它們配到正確的處理方式。」
  - 菊糖：只過濾，不回收、不分泌
  - 肌酸酐：過濾，再加少量分泌
  - PAH：過濾＋分泌
- **💡提示：**「只被濾出來、什麼都不加減的，最能代表過濾量。」
- **動作 ②：**「哪一個的清除率剛好等於 GFR？」〔菊糖〕〔PAH〕
  - 答錯回饋：「PAH 兼具過濾與分泌，用來估腎血漿流量；菊糖的清除率才等於 GFR。」

## 結尾
1. 「過濾的方向？」〔腎絲球→鮑氏囊〕〔鮑氏囊→腎絲球〕
2. 「過不去的是？」〔血球、白蛋白〕〔水、葡萄糖〕
3. 「清除率等於 GFR 的是？」〔菊糖〕〔PAH〕

- **結語：**「血液中的水和可以通過的小分子，經三層過濾膜進入鮑氏囊；血球和白蛋白留在血液裡。用菊糖的清除率可以知道 GFR。」
- **過渡頁空格：**「腎絲球過濾和清除率」
