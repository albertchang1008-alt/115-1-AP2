# 腎臟位置、構造與功能｜學生腳本

## 開場
「腎臟在身體哪裡？切開長什麼樣子？它做哪些工作？6 關之後，你能在圖上指出腎臟的各部分，並說出它們的工作。」〔開始〕

## 第 1 關｜腎臟在身體的哪裡？
- **先認識：** 後腹腔＝腹部後側、腹膜後面的空間。圖上標有「身體右側／左側」，請不要用螢幕的左右來判斷。腎臟位於脊柱兩側；肝臟相關位置使右腎較左腎低。
- **問題：**「請把左腎、右腎放到背後脊柱兩側正確的高度。」
- **動作：** 點腎臟卡，再點高度格（較高／較低）。
- **💡提示：**「身體右邊上方有肝臟。」
- **答對：**「腎臟在後腹腔、脊柱兩側，大約 T12 到 L3；右腎比左腎低。」
- **答錯：**「肝臟在右側，所以右腎比較低。」
- **確認：**「下面哪一句是對的？」
  - A 腎臟在後腹腔，右腎比左腎低（正）
  - B 腎臟在腹膜腔裡面
  - C 左腎比右腎低
  - 答錯回饋：B「腎臟在腹膜後方，屬於後腹腔。」C「是右腎比較低。」

## 第 2 關｜把腎臟切開，看到哪幾層？
- **先認識：** 腎錐體＝髓質裡一個個三角形的構造，有 8–18 個。※ 腎臟切面外為皮質、內為髓質；皮質伸入腎錐體間的部分稱腎柱。
- **問題：**「請把『皮質』『髓質』『腎柱』三個標籤，放到切面圖上的位置。」
- **💡提示：**「先看切面的外圈和內部，再沿著外圈的組織找它往裡延伸到哪裡；回看先認識的三個名稱。」
- **答對：**「外面是皮質，裡面是髓質；皮質伸進腎錐體之間的部分叫腎柱。」
- **答錯（皮質卡）：**「腎臟切面外為皮質。」
- **答錯（髓質卡）：**「腎臟切面內為髓質。」
- **答錯（腎柱卡）：**「皮質伸入腎錐體間的部分稱腎柱。」
- **確認：**「兩個腎錐體之間、跟外層相連的組織是？」
  - A 腎柱（正）
  - B 腎乳頭
  - C 腎盂
  - 答錯回饋：B「腎乳頭在錐體的尖端。」C「腎盂在靠近腎門的收集區。」

## 第 3 關｜尿液從錐體出來，往哪裡走？
- **先認識：** 腎盂位於靠近腎門的收集部，接輸尿管；輸尿管再把尿送到膀胱。
- **問題：**「尿從腎錐體尖端流出來。請在圖上依序點出它經過的地方。」
- **動作：** 依序點「腎乳頭 → 小腎盞 → 大腎盞 → 腎盂」，每點對一個，尿滴就前進一格。
- **💡提示：**「先小後大：小腎盞在大腎盞前面。」
- **答錯：**「集尿管開口在乳頭，尿接著進小腎盞，再到大腎盞、腎盂。」
- **確認：**「腎盂接下來連到哪裡？」
  - A 輸尿管（正）
  - B 尿道
  - C 腎乳頭
  - 答錯回饋：B「尿道在膀胱之後。」C「腎乳頭在腎盂的上游。」

## 第 4 關｜腎臟的門和保護層
- **先認識：** 腎臟外圍由內到外依次為腎被膜、脂肪囊、腎筋膜；內側凹入處為腎門。腎柱是在腎臟裡面、深入腎錐體間的皮質。
- **問題：**「腎臟外面包了三層保護。請從最裡面到最外面，依序點出來。」
- **動作 ①：** 依序點「腎被膜 → 脂肪囊 → 腎筋膜」。
- **💡提示：**「從貼著腎臟表面的地方往外看，對照先認識的包覆順序；內側凹入處是另一個位置，別混在保護層裡。」
- **答錯：**「由內到外依序是：腎被膜、脂肪囊、腎筋膜。」
- **動作 ②：**「腎臟內側凹進去的地方叫什麼？」〔腎門〕〔腎柱〕
  - 答錯回饋：「腎柱在腎臟裡面；內側凹入處是腎門。」

## 第 5 關｜泌尿系統四個器官怎麼分工？
- **先認識：** 腎形成尿液；輸尿管把尿送到膀胱，膀胱暫存尿液，尿道把尿排至體外。尿素、尿酸、肌酸酐是腎會排出的代謝廢物；肌酸酐與肌肉代謝有關。葡萄糖、胺基酸正常可被全部回收。
- **問題：**「請把腎、輸尿管、膀胱、尿道，放到『製造尿／運送尿／儲存尿／排出尿』四格。」
- **💡提示：**「只有一個器官會『做』尿，其他三個是管子或袋子。」※
- **答對：**「腎形成尿液；輸尿管運送、膀胱儲存、尿道排出。」
- **動作 ②：**「腎還會把哪些廢物排出去？」〔尿素、尿酸、肌酸酐〕〔葡萄糖、胺基酸〕
  - 答錯回饋：「葡萄糖、胺基酸正常會被回收，不是要排出的廢物。」

## 第 6 關｜腎臟還會分泌東西
- **先認識：** 腎素啟動 RAAS（腎素—血管收縮素—醛固酮系統），這條連鎖反應調節血壓；紅血球生成素促進紅血球生成；腎將維生素 D 轉為具活性的形式，參與鈣調節。
- **問題：**「腎臟也會分泌物質。請把『腎素』『紅血球生成素』『活化維生素 D』，配到它影響的事：血壓、紅血球、鈣。」
- **💡提示：**「先看名字：紅血球生成素跟哪一個有關？」
- **答對：**「腎素啟動 RAAS 調節血壓；紅血球生成素促進紅血球生成；腎把維生素 D 轉成活性形式，參與鈣調節。」
- **確認：**「腎素主要和哪件事有關？」
  - A 調節血壓（正）
  - B 製造紅血球
  - C 調節鈣
  - 答錯回饋：B「那是紅血球生成素。」C「那是活化維生素 D。」

## 結尾｜一滴尿的旅程
- **畫面：**「腎臟做好一滴尿，請依序回答。」
- **三格：**
  1. 「尿從錐體出來的路線是？」〔腎乳頭→腎盞→腎盂〕〔腎盂→腎盞→腎乳頭〕
  2. 「腎盂之後去哪裡？」〔輸尿管→膀胱→尿道〕〔尿道→膀胱→輸尿管〕
  3. 「腎臟除了做尿，還做什麼？」〔分泌腎素、紅血球生成素，活化維生素 D〕〔儲存尿液〕
- **結語：**「腎在後腹腔，外層皮質、內層髓質；尿從乳頭經腎盞、腎盂進輸尿管；腎還負責內分泌工作。」
- **過渡頁空格：**「腎臟的位置、構造和工作」
