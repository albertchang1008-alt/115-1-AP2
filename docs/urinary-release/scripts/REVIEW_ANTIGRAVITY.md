4. **有沒有一個畫面要同時做兩件事：** 是！打開開關回答 ANP 反應後，動作 ② 又問「誰管量、誰管濃度？把醛固酮、ADH 歸位」。
5. **動作畫得出來、點得到嗎：** 可以。心臟分泌 ANP 飛到腎臟的小動畫，尿中鈉離子噴出。

## 9. 電解質、滲透與離子平衡（electrolyte-balance.md）

### 第 1 關｜溶進水裡會變成幾顆？
1. **問題句看得懂嗎：** 是。先認識有定義電解質與離子。
2. **知道要做什麼動作嗎：** 知道，把三種物質放到 1、2、3 顆的格子。
3. **提示有幫助嗎？是否直接洩漏答案：** 提示「NaCl 分成 Na⁺ 和 Cl⁻；MgCl₂ 裡有兩個 Cl」，對於化學較弱的國中生很關鍵，有講清楚化學式下標 2 代表兩顆氯。
4. **有沒有一個畫面要同時做兩件事：** 否，三張卡分類。
5. **動作畫得出來、點得到嗎：** 可以。三杯水，丟入粒子後在水中拆開成 1、2、3 顆浮動小球。

### 第 2 關｜水往哪邊走？
1. **問題句看得懂嗎：** 是。半透膜先認識有定義。
2. **知道要做什麼動作嗎：** 知道，點箭頭指示水移動方向。
3. **提示有幫助嗎？是否直接洩漏答案：** 有幫助。「水移向離子或分子多的地方」，標準滲透規則。
4. **有沒有一個畫面要同時做兩件事：** 否，點箭頭。
5. **動作畫得出來、點得到嗎：** 可以。U 型半透膜管，左邊淡右邊濃，水往右邊跑、右邊液面升高的動畫。

### 第 3 關｜mEq 和粒子數不一樣
1. **問題句看得懂嗎：** 否。「mEq/L」「電荷」「價數」卡住！國中理化只教過正負電，沒學過「價數」，看到「mEq/L」這種專有名詞會被嚇到。
2. **知道要做什麼動作嗎：** 知道選誰能吸兩倍 Cl⁻（選 Mg²⁺ 或 Na⁺）。
3. **提示有幫助嗎？是否直接洩漏答案：** 有幫助。「看右上角數字：電荷越多吸越多」，成功把抽象的當量轉化成看右上角數字比大小。
4. **有沒有一個畫面要同時做兩件事：** 否，二選一。
5. **動作畫得出來、點得到嗎：** 可以。一個 Mg²⁺ 伸出兩隻手各抓一個 Cl⁻，一個 Na⁺ 只有一隻手抓一個 Cl⁻ 的擬人圖。

### 第 4 關｜鈉和鉀住在哪？
1. **問題句看得懂嗎：** 是。Na⁺ 和 K⁺ 分布內外清楚。
2. **知道要做什麼動作嗎：** 知道把 Na⁺ 丟細胞外、K⁺ 丟細胞內。
3. **提示有幫助嗎？是否直接洩漏答案：** 直接洩漏答案！提示直接給口訣「鈉在外、鉀在內」，這就是把題目的答案一字不差全部講出來，學生不用動腦。建議改成「想一想：鹽巴（NaCl）主要是在血液（細胞外）還是細胞裡面？」。
4. **有沒有一個畫面要同時做兩件事：** 是！放完鈉鉀後，動作 ② 問醛固酮回收哪一個。
5. **動作畫得出來、點得到嗎：** 可以。細胞剖面，內外各有放置插槽。

### 第 5 關｜氯離子
1. **問題句看得懂嗎：** 是。
2. **知道要做什麼動作嗎：** 知道，三選一選陰離子。
3. **提示有幫助嗎？是否直接洩漏答案：** 直接洩漏答案！提示說「陰離子帶負電，看符號右上角的『−』」，而三個選項是〔Cl⁻〕〔Na⁺〕〔K⁺〕，只有 Cl⁻ 頭上有負號，學生連它是氯都不用知道，直接找減號就選對了。
4. **有沒有一個畫面要同時做兩件事：** 是！選完 Cl⁻ 後，動作 ② 又問「Na⁺ 被回收時，Cl⁻ 會怎樣？〔被動跟著被吸收〕〔被排出去〕」。
5. **動作畫得出來、點得到嗎：** 可以。三顆小球選項卡，點擊正確後 Cl⁻ 亮起。

### 第 6 關｜鎂離子
1. **問題句看得懂嗎：** 是。Mg²⁺ 內外位置二選一。
2. **知道要做什麼動作嗎：** 知道，選細胞內或細胞外。
3. **提示有幫助嗎？是否直接洩漏答案：** 直接洩漏答案！提示寫「課本說它是『細胞內主要電解質之一』」，直接把「細胞內」寫在提示裡，毫無懸念。
4. **有沒有一個畫面要同時做兩件事：** 是！回答完細胞內外，動作 ② 問 Mg²⁺ 活化什麼〔代謝的酶〕〔ADH 的分泌〕。
5. **動作畫得出來、點得到嗎：** 可以。細胞內線粒體或酵素反應圖，鎂離子卡入酵素活化孔。
