### 第 1 關｜過濾往哪個方向走？
- **先認識**：「鮑氏囊＝包住腎絲球、接住濾出液體的囊。腎小體由腎絲球與鮑氏囊組成，位於皮質；血液中的水和可以通過的溶質經過濾膜進入鮑氏囊。」
  - 截圖：`390x844-N1-basics.png`
- **動作前問題句（逐字抄畫面）**：「過濾時，水和小分子是從腎絲球（血液）流到鮑氏囊，還是反過來？請點箭頭，讓它指向正確方向。」
  - 截圖：`390x844-N1-before.png`
- **點擊💡提示**：「濾出來的液體最後會變成尿。」（截圖：`390x844-N1-hint.png`）。
- **新手操作路徑**：
  - 點擊箭頭按鈕，使箭頭指向鮑氏囊（血液側至囊側）。
  - 送出通過，顯示答對回饋「血液裡的水和可以通過的溶質，經過濾膜進入鮑氏囊。」（截圖：`390x844-N1-S1-correct.png`）。
- **確認題問題句（逐字抄畫面）**：「濾液在哪裡形成？」
  - 截圖：`390x844-N1-micro.png`
  - 選 A「皮質的腎小體」，送出通過（截圖：`390x844-N1-passed.png`）。
- **重來覆核**：箭頭若指錯方向，顯示回饋，點「再試一次」重來（截圖：`390x844-N1-S1-wrong.png`、`390x844-N1-S1-restarted.png`）。確認題選輸尿管，顯示「形成濾液的位置是皮質的腎小體，不是輸尿管或腎盂。」，按「重新開始這一關」回開頭（截圖：`390x844-N1-micro-wrong-1.png`）。
