### 第 1 關｜三種移動，往哪裡走？
- **先認識**：「管液＝腎小管裡的液體，之後會變成尿。過濾把物質由血液移入鮑氏囊；再吸收把管液中的物質送回血液；分泌把血液中的物質送入管液。」
  - 截圖：`390x844-N1-basics.png`
- **動作前問題句（逐字抄畫面）**：「請把『過濾』『再吸收』『分泌』三個箭頭放到圖上，並指向正確方向。」
  - 截圖：`390x844-N1-before.png`
- **點擊💡提示**：「『再吸收』是拿回來，回到血液。」（截圖：`390x844-N1-hint.png`）。
- **新手操作路徑**：
  - 點擊設定三組箭頭方向：過濾（血液→鮑氏囊）、再吸收（管液→血液）、分泌（血液→管液）。送出正確（截圖：`390x844-N1-S1-correct.png`）。
- **確認題問題句（逐字抄畫面）**：「分泌是把物質從哪裡送到哪裡？」
  - 截圖：`390x844-N1-micro.png`
  - 選 A「血液→管液」，通關（截圖：`390x844-N1-passed.png`）。

### 第 2 關｜尿裡最後剩多少？

  - 截圖：`390x844-N2-before.png`
- **點擊💡提示**：「拿回去的要扣掉，額外送進來的要加上。」（截圖：`390x844-N2-hint.png`）。
- **新手操作路徑**：
  - 第一個方框切換為「－」，第二個方框切換為「＋」，公式形成「排泄量＝過濾量－再吸收量＋分泌量」，點擊送出正確（截圖：`390x844-N2-S1-correct.png`）。
- **確認題問題句（逐字抄畫面）**：「葡萄糖正常會全部被再吸收，所以尿中的葡萄糖會？」

### 第 4 關｜回收能力有上限
- **先認識**：「最大轉運量＝回收葡萄糖的能力上限，課本為 375 mg/min。」
  - 截圖：`390x844-N4-basics.png`
- **動作前問題句（逐字抄畫面）**：「如果過濾出來的葡萄糖越來越多，超過腎小管回收的上限，會發生什麼事？」

- **新手操作路徑**：
  - Step 1：拖動葡萄糖滑桿超過 375 mg/min（例如拉至 400 mg/min），圖上曲線呈現超出上限之排泄斜線，下方解鎖「下一步 →」（截圖：`390x844-N4-S1-correct.png`）。
