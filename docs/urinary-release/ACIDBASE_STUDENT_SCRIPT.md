# 酸鹼互動資訊圖表｜學生腳本 v3.2（教師核定答錯重來「丙」與列內交換）

**對象：** 以國中程度、化學不熟的學生為準。

**每關的畫面：**
- 上：大字問題（完整的一句話）。
- 中：圖。
- 下：「現在要做的事」。
- 右上角：〔💡提示〕按鈕。提示幫忙想，不直接給答案。

**作答規則：**
- 符號第一次出現時，旁邊用小字說它是什麼。
- 一次只做一個動作。
- 操作或配合題答錯：先顯示說明，再出現〔再試一次〕；按下後整步清空重做。
- 確認題答錯：先顯示說明，再出現〔重新開始這一關〕；按下後清空該關所有動作，回到動作①。
- 結尾三格任一格答錯：先顯示說明，再出現〔從第 1 格重來〕；按下後三格清空，心智圖重新遮住。
- 每次重來重新打亂選項與卡片，不保留高亮或已選樣式。整關通過後心智圖才長一枝，接著出現「下一關 →」。
- 配合題選到已被其他列使用的說明：在該列下方顯示〔交換兩列〕〔取消〕，不另開彈出對話框。

**※ 標示的提示：** 屬於生活比喻或一般常識，課本原句裡沒有，需要教師確認可以使用。

## 開場
- **畫面：**「一位急診病人的血液變得太酸了。身體裡有三組『人手』會處理酸：緩衝、肺、腎。接下來 6 關，你要找出答案：酸被接住之後，為什麼還需要肺和腎？」
- **先認識（小卡）：**
  - H⁺（氫離子）：酸的代表，越多越酸。
  - pH：表示酸鹼的數字，越小越酸。※
  - 血液正常 pH 約 7.35–7.45。
- **按鈕：**〔開始〕

## 第 1 關｜三組人手，各做什麼工作？
- **問題：**「下面有三份工作。請把緩衝、肺、腎，分別放到它負責的那一份工作。」
- **工作格：**
  - 「把 H⁺ 暫時抓住，讓 pH 不要變太多」
  - 「把 CO₂ 呼出去」
  - 「把 H⁺ 排到尿裡，把 HCO₃⁻ 留在血液」
- **動作 ①：** 請先點選角色，再選擇它的工作說明。
- **💡提示：**「哪一個器官負責呼吸？先放這一張，剩下兩張就容易了。」
  - 答錯（例如把腎放到『暫時抓住』）：「腎負責把 H⁺ 排到尿裡；在血液裡當場把 H⁺ 抓住的是緩衝。」
- **動作 ②：**「緩衝把 H⁺ 抓住了，這個 H⁺ 已經離開身體了嗎？」〔已經離開〕〔還在身體裡〕
- **💡提示：**「抓住和丟掉一樣嗎？像接住一顆球，球還在你手上。」※
  - 答錯：「抓住不等於排出，H⁺ 還在身體裡，所以還需要肺和腎把酸送走。」

## 第 2 關｜血液酸不酸，看什麼？
- **先認識：** HCO₃⁻（碳酸氫根）＝血液裡的鹼；H₂CO₃（碳酸）＝血液裡的酸。
- **問題：**「課本的公式是 pH＝pKa＋log（鹼／酸）。請把 HCO₃⁻ 和 H₂CO₃ 放進分數的上面和下面。」
- **動作 ①：** 點卡，再點分數的上格或下格。
- **💡提示：**「公式寫『鹼／酸』，鹼在上面。HCO₃⁻ 是鹼還是酸？」
  - 答對：「課本例：6.1＋log（26/1.3）≈7.4，正好在正常範圍。」
  - 答錯：「鹼放上面：HCO₃⁻ 是鹼，放上面；H₂CO₃ 是酸，放下面。」
- **動作 ②：**「如果上面的鹼變多（鹼／酸比變大），pH 會變大還是變小？」〔變大 ↑〕〔變小 ↓〕〔不變〕
- **💡提示：**「鹼變多，血液是變酸還是變不酸？pH 越大表示越不酸。」
  - 答錯：「課本：鹼／酸比增加，pH 上升。」

## 第 3 關｜緩衝有好幾種，它們各在哪裡工作？
- **問題：**「身體不只一種緩衝。請把三種緩衝放到它工作的地方。」
- **地方：** 血液的液體部分（細胞外液）、紅血球裡面、腎小管（尿液形成的地方）。
- **卡片：** 碳酸／HCO₃⁻、血紅素、磷酸鹽。
- **動作 ①：** 請先點選角色，再選擇它的工作說明。
- **💡提示：**「血紅素在哪一種血球裡？磷酸鹽可以在腎小管幫忙接住 H⁺。」
  - 答對：「緩衝不是只有一種，分散在不同地方。」
  - 答錯：錯卡彈回，並說一句：「碳酸／HCO₃⁻ 在血液的液體部分（細胞外液）工作。」「血紅素在紅血球裡面。」「磷酸鹽在腎小管幫忙接住 H⁺。」（只顯示放錯的那張）

## 第 4 關｜肺呼出更多 CO₂，血液會變怎樣？
- **先認識：** CO₂（二氧化碳），課本說它和血液的酸有關，呼出去可以減少酸。
- **動作 ①：** 按〔讓肺呼出更多 CO₂〕，呼氣箭頭變粗。
- **問題：**「肺把更多 CO₂ 呼出去之後，血液會變得比較不酸，還是更酸？」〔比較不酸，pH ↑〕〔更酸，pH ↓〕〔沒有變〕
- **💡提示：**「課本說：呼吸增加 CO₂ 排出，可以減少酸。」
  - 答錯：「CO₂ 呼出去就是把酸帶走，所以血液比較不酸，pH ↑。」

## 第 5 關｜找錯！這張圖的箭頭畫反了
- **圖：** 左邊血液，中間腎小管壁，右邊管液（之後會變成尿）。兩條箭頭，一條寫 H⁺，一條寫 HCO₃⁻，方向都故意畫反。
- **問題：**「腎要把酸丟掉、把鹼留下。這張圖的兩條箭頭都畫反了，請點箭頭讓它轉向，兩條都改好再按〔送出〕。」
- **💡提示：**「H⁺ 是酸，要丟掉，該往尿的方向還是血液的方向？HCO₃⁻ 是鹼，要留下來。」
  - 答對：標籤改成「已校正」。
  - 答錯：只框紅錯的那條：「H⁺ 往管液（尿），HCO₃⁻ 回血液。」

## 第 6 關｜H⁺ 到了尿裡，誰帶它出去？
- **先認識：** NH₃（氨）；它接住 H⁺ 會變成 NH₄⁺（銨）。
- **動作 ①：**「管液裡，誰會接住 H⁺？」〔NH₃〕〔HCO₃⁻〕
- **💡提示：**「HCO₃⁻ 在上一關已經回到哪裡了？」
  - 答對：H⁺＋NH₃ 合成 NH₄⁺。
  - 答錯：「HCO₃⁻ 已回到血液；在管液接住 H⁺ 的是 NH₃。」
- **動作 ②：**「NH₄⁺ 接下來去哪裡？」〔跟尿一起排出〕〔回到血液〕
- **💡提示：**「它已經在管液裡，管液最後會變成什麼？」
  - 答錯：「NH₄⁺ 帶著 H⁺ 跟尿排出，這就是腎在排酸。」

## 結尾｜一滴酸的旅程
- 心智圖先遮住，畫面寫：「血液裡又多了一滴酸。請依序回答，三組人手各做了什麼？」
- 一次亮一格，每答對一格，就揭開心智圖的一枝：
  1. 「緩衝抓住 H⁺ 之後，酸還在身體裡嗎？」〔還在〕〔已排出〕
  2. 「肺呼出的是什麼？」〔CO₂〕〔HCO₃⁻〕
  3. 「腎怎麼處理？」〔H⁺ 丟到尿、HCO₃⁻ 留在血〕〔反過來〕
- 💡提示：每格都有「回看第 X 關」按鈕，點了可以跳回那一關，看完再回來。
- 全部答完後，顯示完整心智圖，並回答開場問題：「緩衝只是暫時抓住酸；真正把酸送走，要靠肺呼出 CO₂、腎把 H⁺ 排到尿並留住 HCO₃⁻。」
- 接著是〔進入第二關考核〕。

## v3 增補（教師 09:24：小檢核改白話、多一道關卡；考核前加鼓勵）
小檢核放在各關動作 ② 之後，第 5 關沒有。答對的選項不變；選項順序打亂。

### 第 1 關｜確認
- 「緩衝抓住 H⁺ 之後，下面哪一句是對的？」
  - A 酸已經全部離開身體了
  - B 酸的變化先被穩住，但還要靠肺和腎把酸送走（正）
  - C 有了緩衝，肺和腎就不用工作了
  - D 只要排尿，就不需要緩衝
- 💡「想想接球：球接住了，還要有人把球丟出去。」
- 答錯回饋：
  - A：「抓住不等於離開，酸還在身體裡。」
  - C：「三組人手是分工，不是互相取代。」
  - D：「緩衝是當場先穩住；排尿是之後的事。」

### 第 2 關｜確認
- 「pKa 是公式裡固定的數字。※ pKa 不變時，如果鹼／酸的比值變大，pH 會怎樣？」
  - A 變小
  - B 不變
  - C 變大（正）
  - D 只要知道比值變大，就能算出準確的 pH 數字
- 💡「回想剛才：鹼放上面，上面變多，pH 往哪邊？」
- 答錯回饋：
  - A：「鹼在上面；鹼變多，pH 變大。」
  - B：「比值變了，pH 就會跟著變。」
  - D：「比值變大只告訴你 pH 往上；要算出數字，還需要真正的數值。」

### 第 3 關｜確認
- 「關於緩衝，下面哪一句是對的？」
  - A 緩衝抓住 H⁺，H⁺ 就離開身體了
  - B 身體只有碳酸這一種緩衝
  - C 有緩衝在，肺和腎就停止工作
  - D 緩衝能抓住 H⁺、讓 pH 不亂跳，但酸最後要去哪裡，還要另外看（正）
- 💡「這一關你放了三種緩衝卡，它們在三個不同地方。」
- 答錯回饋：
  - A：「抓住不等於離開。」
  - B：「剛剛你放了三種緩衝：碳酸／HCO₃⁻、血紅素、磷酸鹽。」
  - C：「三組人手一起工作，不是誰取代誰。」

### 第 4 關｜確認
- 「如果肺真的把更多 CO₂ 呼出去了，下面哪一句是對的？」
  - A 血液裡的酸變少（正）
  - B 血液裡的酸變多
  - C 只要呼吸變快，就一定呼出更多 CO₂
  - D 這表示腎已經停止排酸
- 💡「回想剛才：CO₂ 呼出去，是把什麼帶走？」
- 答錯回饋：
  - B：「CO₂ 呼出去是把酸帶走，酸會變少。」
  - C：「課本提醒：要看 CO₂ 有沒有真的排出去，不能只看呼吸次數。」
  - D：「肺和腎是一起工作，不是輪流。」

### 第 6 關｜確認
- 「腎把 NH₄⁺ 排到尿裡，又把 HCO₃⁻ 留在血液。這兩件事是什麼關係？」
  - A 互相抵消，等於沒做
  - B 尿變酸，表示血液也一定變酸
  - C 一起合作：把酸丟掉、把鹼留下（正）
  - D 有緩衝，就不用排酸
- 💡「一個是丟掉酸，一個是留下鹼。對血液來說，兩件事都讓血液往哪個方向變？」
- 答錯回饋：
  - A：「丟掉酸、留下鹼，方向相同，不會抵消。」
  - B：「尿和血液是不同的地方；把酸性的尿排掉，是在幫血液 pH 回升。」
  - D：「回想第 3 關：抓住不等於丟掉。」
