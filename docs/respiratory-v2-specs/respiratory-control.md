## 教學內容與功能契約

**學習範圍**：延髓與橋腦的呼吸中樞依化學受器與肺牽張受器的訊息調整呼吸；CO₂ 是最主要的驅動因素，也連動血液酸鹼。

統計卡保留：腦脊髓液 H⁺／中樞化學受器的直接刺激；PO₂＜約 60 mmHg／周邊受器明顯反應；pH 7.35–7.45／正常血液。

實驗室的預測題、答案與回饋、第一關6題先備、第二關5題情境、SDK事件、回讀與通關邏輯全部保留。現行完整content快照見 `CONTENT_BASELINE.json`；不重寫核定題目。

## Overview 三狀態

| state | 核定名稱／原文說明 | 紅色粗體標籤 | 圖面變化／數值 |
|---|---|---|---|
| state-1 | 閉氣：PCO₂ 逐漸上升，CO₂ 穿過血腦障壁使腦脊髓液 H⁺增加，刺激中樞化學受器，驅動吸氣 | CO₂、腦脊髓液H⁺、中樞化學受器 | 閉氣路線顯示CO₂穿越血腦障壁、H⁺增加、促進吸氣；其他路線降至低對比但不隱去必要解剖。 |
| state-2 | 深吸氣：肺牽張受器受牽拉，經迷走神經傳入，抑制吸氣（赫鮑二氏反射） | 肺牽張受器、迷走神經、抑制吸氣 | 牽張經迷走傳入中樞，終點抑制吸氣；不出現化學刺激箭頭。 |
| state-3 | 初到高山：大氣壓降低，吸入氧分壓下降，周邊化學受器使換氣增加，CO₂ 排出增加、pH 上升 | 周邊化學受器、換氣增加 | 高山氧分壓降低經周邊受器使換氣增加，CO₂排出增加、pH上升；不顯示高山右移曲線。 |

狀態由 `.state-figure[data-state]` 驅動；只變圖面，不改按鈕名稱／說明文字。未列為紅字者維持一般色。紅字加粗，血流含氧／缺氧顏色仍保留醫學語意。
