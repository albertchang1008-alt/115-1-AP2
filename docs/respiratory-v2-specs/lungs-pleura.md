## 教學內容與功能契約

**學習範圍**：右肺三葉、左肺兩葉，外有胸膜包覆；肺泡由三種細胞組成，表面張力素讓大小肺泡都能維持擴張。

統計卡保留：右 3 左 2／肺葉；第二型／分泌表面張力素；P＝2T/r／拉普拉斯關係。

實驗室的預測題、答案與回饋、第一關6題先備、第二關5題情境、SDK事件、回讀與通關邏輯全部保留。現行完整content快照見 `CONTENT_BASELINE.json`；不重寫核定題目。

## Overview 三狀態

| state | 核定名稱／原文說明 | 紅色粗體標籤 | 圖面變化／數值 |
|---|---|---|---|
| state-1 | 表面張力相同：小肺泡半徑小、所需壓力較大，較易塌陷 | 表面張力、P＝2T/r | 大小肺泡半徑固定，T相同；小肺泡P相對較大，不設定比例數字。 |
| state-2 | 有表面張力素：表面張力降低，小肺泡也能維持擴張 | 表面張力素 | 在內表面加表面張力素薄層，T下降；不自動改變r以掩蓋原因。 |
| state-3 | 表面張力素不足（早產兒）：肺泡不易維持擴張，呼吸費力 | 表面張力、表面張力素 | 表面張力素薄層明顯變少、不連續；薄層減少，顯示擴張困難，無新增病名。 |

狀態由 `.state-figure[data-state]` 驅動；只變圖面，不改按鈕名稱／說明文字。未列為紅字者維持一般色。紅字加粗，血流含氧／缺氧顏色仍保留醫學語意。
