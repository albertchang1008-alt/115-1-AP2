## 教學內容與功能契約

**學習範圍**：四個肺容積組成四個肺容量；扣掉死腔才是真正到達肺泡的換氣；用 FEV₁ 與 FVC 比較阻塞性與限制性型態。

統計卡保留：TV 500 mL／潮氣容積；150 mL／解剖死腔；VA＝（TV－VD）×F／肺泡通氣量。

實驗室的預測題、答案與回饋、第一關6題先備、第二關5題情境、SDK事件、回讀與通關邏輯全部保留。現行完整content快照見 `CONTENT_BASELINE.json`；不重寫核定題目。

## Overview 三狀態

| state | 核定名稱／原文說明 | 紅色粗體標籤 | 圖面變化／數值 |
|---|---|---|---|
| state-1 | 淺快：淺快 150 mL×40 次 → 肺泡通氣 0 | 淺快、肺泡通氣量 | TV150、VD150、F40；總6000、死腔6000、肺泡0 mL/min。 |
| state-2 | 一般：一般 500 mL×12 次 → 4200 mL/min | 一般、肺泡通氣量 | TV500、VD150、F12；總6000、死腔1800、肺泡4200 mL/min。 |
| state-3 | 深慢：深慢 1000 mL×6 次 → 5100 mL/min | 深慢、肺泡通氣量 | TV1000、VD150、F6；總6000、死腔900、肺泡5100 mL/min。 |
