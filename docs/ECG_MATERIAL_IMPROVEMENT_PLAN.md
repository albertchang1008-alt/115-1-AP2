# 心電圖基礎與心率調控教材改善計畫

建立：2026-09-23
狀態：**待教師核定；不得發布或覆寫既有教材**

## 1. 目的與範圍

將教師提供的單檔 HTML 初稿轉為本平台可發布的互動教材。目標是讓五專學生能以圖像、互動與兩階段題目理解 ECG 的基本電生理，並只蒐集去識別的探索、停留、作答與通關事件。

本計畫不做學生個案判讀、不提供疾病診斷，也不修改既有 `public/materials/`。原始初稿保留為審稿來源；正式版另建新版本資料夾，內容或題目 ID 改動後以新版本發布。

## 2. 先由教師核定的三項決策

| 決策 | 建議 | 理由 |
| --- | --- | --- |
| 教材範圍 | 採「ECG 基礎」六個節點；進階異常波形另做後續教材 | 平台固定模型為 6 節點、6 題先備、5 題病例；可避免把基礎生理與臨床診斷混在同一份教材。 |
| 正式版本 | `ecg-basics-v1` | 尚未發布，應使用獨立 slug 與版本，避免影響既有診斷資料。 |
| 臨床異常內容 | `深 Q 波／高 R 波／T 波倒置` 整段先不納入 v1，待心臟科或具 ECG 教學資格者以來源逐項審核 | 這些圖形都不能單獨作診斷；原稿的病因連結過度確定，對初學者有風險。 |

教師若要保留八個節點，必須明確覆寫「六節點」預設，並以 8 作為後台探索分母；不得在製作中任意混用 6 與 8。

## 3. 核定後的教材藍圖

### 六個知識節點

| ID | 主題 | 由初稿處理方式 |
| --- | --- | --- |
| `ecg-basics-node-01` | P 波、心房去極化與機械收縮 | 保留，但改成「電活動通常先於機械反應」並呈現短暫電機延遲。 |
| `ecg-basics-node-02` | PR 間隔與房室傳導 | 保留。區分 PR 間隔與 AV node 生理延遲，避免把兩者視為同義。 |
| `ecg-basics-node-03` | QRS 與被掩蓋的心房再極化 | 保留；圖解 Q、R、S 是命名規則，並說明不是每導程皆必然出現。 |
| `ecg-basics-node-04` | ST、T 與 QT | 保留為概念示意；將「ST 等於 Phase 2」調整為較精確的「ST 與心室整體處於高原期有關」。 |
| `ecg-basics-node-05` | R-R、心率與自主神經／呼吸變異 | 合併原節點 5、6；把 R-R 定義為相鄰 R 波（心室去極化）間期，不等同臨床診斷。 |
| `ecg-basics-node-06` | 十二導程的貼片與觀測角度 | 保留「10 個電極建立 12 個導程」；修正位置圖標示，補上這是教學示意、實作由受訓人員處理。 |

### 兩階段題目

- 第一關：6 題先備題，逐題答對才解鎖下一題；每次錯答顯示提示與對應節點回讀入口。
- 第二關：5 題情境題，每題錯答只給提示並要求回讀；一輪五題皆正確才通關。
- 選項在每次進題時洗牌；題幹順序維持教學順序。題目 ID 與正解由內容檔固定管理，不能以洗牌後索引判斷正解。
- 題目須重新審核唯一正解、來源依據與用語；不以「診斷錯誤」稱呼學生作答。

## 4. 實作工作分期

### P0：醫學內容與來源審稿（發布前置條件）

1. 教師指定課本章節、頁碼或可引用的 ECG 教材作唯一內容依據。
2. 逐項核對 P、PR、QRS、ST、T、QT、R-R 的定義、測量起迄與正常值範圍。
3. 改寫下列高風險表述：
   - 心率滑桿不可僅依 bpm 標示為「竇性過緩／過速」；改為「模擬較慢／較快的心率區間」，加上非診斷聲明。
   - 移除「高大 R 波＝左心室肥大」、「T 波倒置＝急性缺血」等單一波形直接對應疾病的敘述。
   - 十二導程貼片位置改為有來源的簡化圖，或刪除精確肋間定位以免錯誤教學。
4. 教師確認六節點名稱、11 題內容與完成規則後，內容才可凍結進 v1。

### P1：以教材元件庫重建介面

1. 建立 `materials-src/ecg-basics/content.json`，使用元件庫的內容型別與驗證器；不直接搬運 1,400 行手寫頁面。
2. 以 inline SVG 重畫每個知識節點圖。所有圖中文字在手機至少 12px、桌機至少 14px；不可用 emoji 當圖示。
3. 移除 Tailwind CDN；正式輸出為單檔自足 HTML，僅保留平台 SDK 的公開網址。
4. 改為節點卡「圖示＋標題＋摘要」和可展開內容；展開鈕使用原生 `button`、`aria-expanded`、`aria-controls`，並提供可見焦點。
5. 實作鍵盤 Tab／Enter／Space 操作；標籤頁增加方向鍵切換與正確的焦點、`aria-selected`、tabpanel 關係。
6. 所有動畫納入 `prefers-reduced-motion`；canvas 若保留，提供同等資訊的文字替代。

### P2：重寫心率示意模擬器

1. 初始載入及視窗尺寸改變時，都依實際容器與 `devicePixelRatio` 設定 canvas；避免預設 300×150 被放大而模糊。
2. 滑桿明確只模擬 R-R 間期／節律密度；QRS 寬度保持不因心率等比例縮放。PR、QT 的教學變化若要呈現，需由內容審稿後使用明確而保守的模型。
3. 不顯示虛假的 `25 mm/s`、`10 mm/mV` 校準；若無真正刻度換算，標為「示意 Lead II 形態」。
4. 以描述區宣告目前設定及公式 `HR = 60 / R-R`；範圍與提示用語不做病人診斷。

### P3：平台診斷串接

1. 載入 `https://albertchang1008-alt.github.io/115-1-AP2/materials/course-learning.js`。
2. 第一次展開節點時呼叫 `CourseLearning.explore(nodeId)`；前景有效停留時間使用共用追蹤方法送 `nodeTime(nodeId, seconds)`。
3. 每次選答都呼叫 `CourseLearning.answer(questionId, correct)`；使用提示時呼叫 `CourseLearning.hint(questionId)`。
4. 僅第二關五題全對時呼叫一次 `CourseLearning.complete()`。重玩可保留教材內回饋，但不得覆寫平台首答診斷。
5. 不讀取或傳送姓名、信箱、學號、登入權杖；不加入 GA4，除非教師另行核定去識別事件設計。

### P4：建置、驗收與發布準備

1. 以 `npm run materials:build ecg-basics` 產出 `public/materials/ecg-basics-v1/index.html`，由工具更新 `shared/materials.ts`；分母應為 nodeTotal 6、questionTotal 11。
2. 以 `npm run materials:shots ecg-basics` 驗收 390×844 與 1280×800；每個節點與模擬狀態都要截圖。
3. 通過 `npm run check`、`git diff --check`，再用 iframe、重新整理、離線後恢復、測試學生帳號走完整流程。
4. 教師後台新增 HTML 互動教材活動，填入正式 HTTPS 網址、版本、節點分母 6、題目分母 11；先儲存草稿並預覽，教師確認後才發布。

## 5. 驗收清單

- [ ] 教師已核定內容來源、六節點、11 題與非診斷界線。
- [ ] 390px 不橫向捲動；SVG 文字清楚且沒有互相遮蓋。
- [ ] 鍵盤可完成節點、標籤、篩選、題目與回讀；焦點始終可見。
- [ ] 減少動態設定下不播放干擾性動畫，仍能理解圖表。
- [ ] 首次展開每節點只送一次探索；停留時間只計前景有效時間。
- [ ] 每一次選答、提示與全對通關皆有正確 SDK 事件；非全對絕不送 completed。
- [ ] 重新整理、重玩、離線補送與 iframe 真實測試皆無 console error。
- [ ] 教師診斷頁的節點／題目分母與教材內容一致；資料只用於教學線索。

## 6. 交付物與不做事項

交付物為本計畫、`content.json`、元件庫建置出的單檔教材、素材授權清單、截圖報告與教師活動設定紀錄。此計畫不授權發布、不改寫原始初稿、不把教材行為當成學生能力或臨床診斷證據。
