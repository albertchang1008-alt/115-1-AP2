## 適用與基本流程

後續新增或修改配合題，採「每列直接選擇」，順序固定為先選角色，再選該角色的工作說明。保留配對學習目標，不改為單選題，也不要求拖曳或連線。
每個角色各占一列；左側角色按鈕，右側工作說明選單。取消過高的大型圖卡，讓學生容易同時看到各列與檢查按鈕。
頂端指示：「請先點選角色，再選擇它的工作說明。」角色可依題目替換，例子為緩衝／肺／腎。

1. 點任一角色，該列反白並展開工作說明選單；點該列的說明欄也可開啟，不必精準點小箭頭。
2. 每列提供相同的全部說明選項；不預選答案、不在敘述旁標示正確角色。
3. 選取後填入該列並收起選單；更新「已完成N／總組數」。不限配對順序。
4. 點已選說明可直接修改，不必先清除。
5. 全部列選完才啟用「檢查配對」；統一檢查前不逐列揭曉正解。

## 第一次進入該題的引導

首次進入自動提供簡短、可略過的實際操作引導，不代填答案、不提示哪個配對正確。

| 步驟 | 提示與畫面 | 前進條件 |
|---|---|---|
| 先選角色 | 「先點選一個角色，決定你要幫誰配對。」突出角色按鈕，其餘暫時淡化。 | 學生點任一角色。 |
| 再選說明 | 「再從選單中，選出你認為屬於這個角色的工作說明。」突出已展開的選單。 | 學生選取一段說明。 |
| 繼續完成 | 「已完成一組！請配好另外幾組，再按『檢查配對』。想修改時，點原本的說明即可。」 | 點「知道了」，繼續作答。 |

引導中的選擇即為學生這次真實作答，不自動視為答對，也不鎖定答案。提示隨題目總組數調整，不把所有題目寫死為三組。
提供「略過引導」及隨時可重看的「操作說明」入口。同一帳號、同一裝置對同一題完成或略過引導後不再自動顯示；換裝置可再顯示一次。
本配合題首次引導採學生實際操作、不代填；其他題型的既有自動示範規則仍依各自核定方案處理。

## 選項重複與交換

某段說明已被另一角色選用時，仍顯示該選項，標示「目前配給：○○」。
學生選取已用說明時，在該列下方就地提供「交換兩列」或「取消」，不使用彈出對話框；不暗中搬動或刪除另一列答案，不讓選項無聲失效。

## 檢查與回饋

- 全對：顯示「配對正確」，提供「下一步」。
- 部分錯誤：標出錯誤並先顯示說明，再出現「再試一次」。按下後所有列全部清空並重新打亂說明順序，不保留正確列。
- 整關通過確認題之後心智圖才長枝；確認題答錯須清空整關並回到動作①（教師 10/21 15:04 答錯重來「丙」）。
- 回饋使用文字及圖示，不能只靠紅綠色。
- 「提示」處理內容線索；「操作說明」處理怎麼操作，兩者分開。
- 配對完成並按「下一步」後，才呈現後續判斷題；不在同畫面同時要求配對與另一種作答。

## 驗收要點

首次引導可完成或略過、能重看；不代填或洩答；角色→說明步驟清楚；手機容易找到選項與提交；三組／多組答案都可修改；交換有明確選擇；提交前不揭曉答案；部分錯誤全部列清空重作且重新打亂。
