## 1. 共用底圖（一張畫好，三處共用）
- 新增 `materials-src/figures/major-vessels-anatomy-base.svg`，供以下三處使用：
  - 「追蹤一滴血」實驗室
  - 脈搏點位圖
  - 節點總覽圖：如果 `major-vessels-overview.svg` 也是火柴人風格，一併換掉
- 視角：正面、解剖學姿勢（手掌朝前）。圖頂固定標示「圖左＝人體右」。
- 人體輪廓：淡色、柔和的實心剪影，比例寫實（頭身比約 1:7.5），不要火柴人或膠囊形四肢。
- 器官：形狀寫實、填色柔和、加細描邊，可以有一點陰影。
  - **心臟**：位於胸腔中央偏人體左側，心尖朝人體左下；粉紅色。
  - **肺**：淡色半透明，可省略。
  - **肝臟**：在橫膈下方、人體右上腹（圖的左側）的大楔形；右葉大，左葉延伸越過中線；褐色。
  - **胃**：在人體左上腹（圖的右側）、肝臟左葉下方的 J 形；淡粉米色。
  - **小腸**：淡色、低存在感即可。
  - **腎臟**：可省略。
- 血管：畫成有粗細的管狀，近心端粗、遠心端漸細；用平滑貝茲曲線，不要直角折線。動脈紅、靜脈藍，動靜脈並行時略微錯開。

## 2. 解剖走向（驗收逐項核對）
- **主動脈**：
  - 升主動脈從心臟往上，接主動脈弓，弓向人體左後方。
  - 主動脈弓三分支依序：頭臂動脈 → 左頸總動脈 → 左鎖骨下動脈。頭臂動脈再分為右鎖骨下動脈與右頸總動脈。
  - 降主動脈走中線略偏人體左側，穿過橫膈後成為腹主動脈。
  - 約在肚臍高度（L4）分叉成左右髂總動脈 → 髂外動脈 → 股動脈 → 膕動脈（膝後，用虛線表示在後側）→ 脛前、脛後動脈。
  - 腹腔幹在橫膈正下方從腹主動脈前面分出，分支到胃。
- **上肢動脈**：鎖骨下動脈 → 腋動脈 → 肱動脈（上臂內側）→ 在肘窩分成橈動脈（拇指側）與尺動脈（小指側）。
- **腔靜脈**：
  - 上腔靜脈在升主動脈的人體右側，下接右心房。
  - 頭臂靜脈左右各一，左側較長，斜跨過中線匯入上腔靜脈。
  - 下腔靜脈在腹主動脈的人體右側，向上經過肝臟後方進入右心房。
  - 肝靜脈是幾條短的血管，在橫膈正下方匯入下腔靜脈。
- **肝門靜脈**：由胃及腸的靜脈匯集成肝門靜脈，向上、往人體右側進入肝門（肝臟下緣）。
- **下肢靜脈**：與動脈並行，股靜脈 → 髂外靜脈 → 髂總靜脈 → 下腔靜脈。
