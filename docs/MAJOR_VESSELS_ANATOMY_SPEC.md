  - **心臟**：位於胸腔中央偏人體左側，心尖朝人體左下；粉紅色。

## 2. 解剖走向（驗收逐項核對）
- **主動脈**：
  - 升主動脈從心臟往上，接主動脈弓，弓向人體左後方。
  - 主動脈弓三分支依序：頭臂動脈 → 左頸總動脈 → 左鎖骨下動脈。頭臂動脈再分為右鎖骨下動脈與右頸總動脈。
  - 降主動脈走中線略偏人體左側，穿過橫膈後成為腹主動脈。
  - 約在肚臍高度（L4）分叉成左右髂總動脈 → 髂外動脈 → 股動脈 → 膕動脈（膝後，用虛線表示在後側）→ 脛前、脛後動脈。
  - 腹腔幹在橫膈正下方從腹主動脈前面分出，分支到胃。
- **上肢動脈**：鎖骨下動脈 → 腋動脈 → 肱動脈（上臂內側）→ 在肘窩分成橈動脈（拇指側）與尺動脈（小指側）。
- **腔靜脈**：
  - 上腔靜脈在升主動脈的人體右側，下接右心房。
  - 頭臂靜脈左右各一，左側較長，斜跨過中線匯入上腔靜脈。
  - 下腔靜脈在腹主動脈的人體右側，向上經過肝臟後方進入右心房。
  - 肝靜脈是幾條短的血管，在橫膈正下方匯入下腔靜脈。
- **肝門靜脈**：由胃及腸的靜脈匯集成肝門靜脈，向上、往人體右側進入肝門（肝臟下緣）。
- **下肢靜脈**：與動脈並行，股靜脈 → 髂外靜脈 → 髂總靜脈 → 下腔靜脈。
