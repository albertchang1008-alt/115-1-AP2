# 課堂點名寄信程式：建立步驟（給教師）

平台不會自己寄信。寄信是由**您自己學校 Google 帳號裡的一支小程式**代寄，寄件人就是您本人的學校信箱。
這份文件帶您把它建立起來，大約 10 分鐘，只需要做一次。

這支程式只會寄信，不會讀寫您的試算表、文件或雲端硬碟。

## 會用到的東西
- 您的學校 Google 帳號（平常部署平台用的那一個）。**一定要用學校帳號建立與部署**：個人 gmail.com 帳號每天只能寄給約 100 位收件人，學校帳號是 1,500 位。
- 程式內容：程式庫裡的 `apps-script/AttendanceMailer.gs`（整個檔案）。
- 一組密鑰：一串 32 個字以上的英文與數字，您自己產生（步驟 3）。

## 步驟

### 1. 建立專案
1. 用**學校帳號**開啟 <https://script.google.com/>（右上角頭像確認不是個人 Gmail）。
2. 按左上角〔新專案〕。
3. 點畫面最上方的「未命名的專案」，改名為「課堂點名寄信程式」。

### 2. 貼上程式
1. 畫面中間的編輯區裡原本有幾行 `function myFunction() {…}`，全部選取後刪掉。
2. 打開 `apps-script/AttendanceMailer.gs`，全部複製，貼進編輯區。
3. 按上方的磁碟片圖示（儲存）。

### 3. 設定密鑰
1. 先產生一組密鑰。最簡單的方法：在 Mac 的「終端機」貼上這一行後按 Enter，畫面會出現一串字，把它複製起來。
   ```sh
   openssl rand -hex 24
   ```
2. 回到 Apps Script，按左側的齒輪圖示〔專案設定〕。
3. 捲到最下面「指令碼屬性」，按〔新增指令碼屬性〕。
4. 「屬性」填 `MAIL_KEY`，「值」貼上剛剛那一串字，按〔儲存指令碼屬性〕。

密鑰請不要貼到 LINE、Email 或任何對話裡，也不要放進程式庫。

### 4. 授權並寄一封測試信給自己
1. 按左側的〈 〉圖示回到〔編輯器〕。
2. 編輯區上方有一個函式下拉選單，選 `testSendToMyself`，按〔執行〕。
3. 第一次會跳出「需要授權」：按〔審查權限〕→ 選學校帳號 → 按〔允許〕。它只要求「以您的身分傳送電子郵件」。
4. 到學校信箱確認收到「課堂點名寄信程式測試」。信裡會寫今天還可以寄給幾位收件人。

### 5. 部署成網頁程式
1. 按右上角〔部署〕→〔新增部署作業〕。
2. 「選取類型」旁的齒輪 → 選〔網頁應用程式〕。
3. 「執行身分」選 **我**。
4. 「誰可以存取」選 **所有人**。（沒有密鑰的人打開網址只會看到一行說明，不能寄信。）
5. 按〔部署〕。
6. 複製畫面上的「網頁應用程式網址」，長得像 `https://script.google.com/macros/s/一長串/exec`。

### 6. 貼回平台
1. 進平台教師後台 →〔點名〕→〔寄信設定〕。
2. 「寄信程式網址」貼步驟 5 的網址；「密鑰」貼步驟 3 的那一串字。
3. 填各班的導師姓名與信箱、信件署名；需要的話填「每日預設寄送時間」。
4. 按〔儲存〕。畫面顯示「寄信程式：已設定」就完成了。

密鑰存進平台後不會再顯示出來；忘記了就照步驟 3 重新產生一組，Apps Script 與平台兩邊都換成新的。

## 之後如果改了程式（重要）
Apps Script 的網址綁定「部署版本」。**程式內容更新後，光是貼上並儲存不會生效，一定要重新部署成新版本**：
1. 把 `apps-script/AttendanceMailer.gs` 的新內容整份貼上、儲存。
2. 〔部署〕→〔管理部署作業〕→ 鉛筆圖示 →「版本」選〔新版本〕→〔部署〕。
3. 網址不變，平台不用重貼。

2026-11-19 的版本將去重紀錄改存「指令碼屬性」（PropertiesService），保存期限為 **180 天**（取代原本僅 6 小時的快取），並會在每次處理時自動清理已滿 180 天的舊紀錄，保留 `MAIL_KEY` 與其他設定。
平台在不確定上一次有沒有寄出去（例如網路中斷）而於當日或隔日排程重送時，寄信程式認得編號就不會寄第二封。
如果您在這之前就已經部署過舊版，請照上面三步驟更新；沒更新的話信還是寄得出去，但跨日重寄保護不會生效，網路中斷時學生仍可能收到兩封。

已知限制：
- 若信件已寄出、但在寫入去重紀錄前發生極短暫的中斷，重送時仍可能再寄一次。
- 若未到通知寄送結果不明（其實已寄出），而教師在重試前就把學生改回「準時」，平台可能不會寄出更正信；學生可在「我的出缺席」看到最新狀態，教師可在寄送紀錄看到該筆失敗紀錄。

## 每天可以寄幾封
Google 官方說明（Apps Script 配額）：<https://developers.google.com/apps-script/guides/services/quotas>
- 「Email recipients per day」：Google Workspace 帳號每天 1,500 位收件人；一般 gmail.com 帳號每天 100 位。（2026-11-17 查閱）
- 學校帳號屬於 Google Workspace for Education，適用 1,500 那一欄。實際數字以步驟 4 測試信裡的「今天還可以寄」為準；如果顯示接近 100，請洽學校資訊單位。
- 點名一天的量：每節未到的學生各一封，加上每班導師一封，通常是個位數到幾十封，遠低於上限。
- 額度用完時，平台的寄送紀錄會顯示「失敗：今天的寄信額度已用完」，信會留在待寄，隔天再按寄出即可。

## 停用
〔部署〕→〔管理部署作業〕→ 選該部署 →〔封存〕。封存後平台寄信會失敗並留在待寄，不會遺失。
