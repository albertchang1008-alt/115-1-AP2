# 題庫規畫：參照 v1.9

## 範圍與依據

依 2026-09-11 使用者要求，參照本機「題庫系統-v1.9」的 CreateQuestionBankSheet.gs 欄位、Code.gs 解析器與 index.html 學生介面。此文件是規畫，不表示功能已完成。

維持 Cloud Functions 使用執行服務帳戶讀取已分享的 Google Sheet，再寫入 Firestore 的架構。參考舊系統格式與操作，不遷入舊系統的學生資料、憑證或 Firebase 設定。

## 課程與班級

- 先建立課程，再在課程底下建立班級。
- 課程統一管理單元、教材與題庫版本，各班勾選適用單元。
- 未勾選的單元不出現在該班學生端，也不計入完成度與成績；後端同步限制直接存取。
- 適用單元另設必做／選做、門檻、開放時間及期限；不能用「選做」代替「未提供」。

## 題型

- 保留「單選／圖片」題型選項，支援 A–D 選項；現有平台 A–H 的擴充能力保留。
- 依 v1.9，圖片題是題幹附圖搭配答案選項；舊版並非每個答案選項各有圖片欄位。
- 保留「圖片網址」，同步與預覽需檢查網址，圖片題缺圖列為可定位的錯誤。
- 作答、閃卡、錯題複習、交卷後解析及教師預覽均呈現題目附圖；可放大查看，載入失敗顯示提示。
- v1.9 支援連續圖片題沿用上一列圖片。相容匯入如保留此規則，僅限同課程、同單元的連續圖片題，遇文字题／課程或單元切換即重設；同步預覽須顯示最終圖片網址，避免誤配。

## 兩種解析

每題可同時維護兩種解析，獨立欄位與獨立區塊呈現，不互相覆蓋。

| 類型 | 內容 |
|---|---|
| 傳統解析 | 正解理由、其他選項的辨析與完整說明；沿用 v1.9「解析」欄 |
| 蘇格拉底式解析 | 核心概念、常見誤解、① 先看題幹、② 比較觀念、③ 推回答案 |

- 蘇格拉底式解析以明確中文標籤依序呈現，可逐步展開；內容來自教師維護欄位。
- 一般測驗交卷後顯示；閃卡與錯題複習依既有作答回饋時機顯示，不提前洩漏正解。
- 空白欄位不顯示空卡片；只有傳統解析或只有蘇格拉底式解析的題目仍可使用。
- 保留講義標題、講義連結及補強資源的相容規畫，與兩種解析分開呈現。

## Google Sheet 欄位相容

建議教師使用中文欄位，讀取器同時相容現有英文欄位。

| 中文欄位 | 平台欄位／處理 |
|---|---|
| 課程代碼 | courseId；相容既有「課程」欄，分頁名稱對應單元代碼 |
| 題目ID | id；同步時須穩定且單元內唯一 |
| 問題 | text |
| 選項A～選項D | options；以固定選項 ID 對應答案，不因空白欄而移位 |
| 解答 | answer；相容 v1.9 支援的表示法，無法唯一對應時回報錯誤 |
| 解析／傳統解析 | explanation |
| 核心概念 | socratic.concept |
| 常見誤解 | socratic.misconception |
| ① 先看題幹 | socratic.hint1 |
| ② 比較觀念 | socratic.hint2 |
| ③ 推回答案 | socratic.hint3 |
| 題型 | 新增明確題型欄位 |
| 圖片網址 | image |

舊版 subject／chapter 自動生成課程與主題 ID 的邏輯，不直接套用至新平台自訂課程／單元代碼；匯入時需明確對應。

## 現況差距與驗收

目前模型已有 explanation、socratic 與 image，但 Sheets 解析器未完整相容 v1.9 中文欄位，題型無明確欄位；蘇格拉底式呈現缺少各步驟標籤，教師題庫預覽也未完整顯示附圖與兩種解析。

統一驗收涵蓋：文字題、圖片題、連續共圖、空白圖片、圖片失效、只有一種解析、兩種解析並存、答案格式轉換、重複題目 ID、不同班級可見單元、題庫更新及歷史版本保留。實作與驗證狀態另行記錄。
