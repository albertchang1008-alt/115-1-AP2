# 互動資訊圖表規格：課前／課後雙軌

> 建立 2026-09-13。對應 `INTERACTIVE_LEARNING_PLAN.md` 的教材端實作規格。
> 每個單元產出**兩份** HTML 教材，放在 `public/materials/<unit>-pre-v1/` 與 `<unit>-post-v1/`。

## 為什麼分兩份

同一份圖表沒辦法同時服務兩種時機。課前學生還沒有概念骨架，給全景圖只會淹沒他；
課後學生需要的是把散落的片段接起來，這時給速記卡又太淺。

| | 課前｜必要記憶 | 課後｜全面統整 |
|---|---|---|
| 時機 | 上課前 10 分鐘 | 上完課、考前 |
| 目的 | 讓學生**聽得懂課** | 讓學生**看見結構** |
| 認知層次 | 記憶為主 | 了解、應用、分析 |
| 內容 | 名詞、數值、分類、順序 | 機轉、關聯、比較、考點 |
| 份量 | 30～40 個記憶點 | 全章概念 |
| 互動 | 翻卡、配對、快速自測 | 探索節點、概念地圖、闖關 |
| 完成條件 | 自測全對一輪 | 闖關通過 |

## 共同技術規格

1. **單檔自足**：CSS／JS 全部 inline，圖用 inline SVG 或 data URI。iframe 沙箱不保證外部資源可載入。
2. **引入平台 SDK**：`<script src="../course-learning.js"></script>`，並在互動時呼叫
   - `CourseLearning.explore(nodeId)`　學生點開一個知識節點
   - `CourseLearning.answer(questionId, correct)`　作答（**首次作答才是診斷依據**，教材端不要重送）
   - `CourseLearning.hint(questionId)`　使用提示
   - `CourseLearning.complete()`　通關
3. **不接觸學生身分**：教材永遠不取得姓名、信箱、學號、權杖。平台依登入身分歸屬紀錄。
4. **教材內自有回饋**：星星、徽章、通關動畫留在教材內，平台只顯示「本活動已完成」。
   診斷指標低不撤銷通關（見 `INTERACTIVE_LEARNING_PLAN.md`）。
5. **手機優先**：最小 360px 寬可用；不得橫向捲動。
6. **GA4 選用**：只送去識別事件（單元代碼、節點代碼、對錯），**不送任何識別碼**。
   未設定 `GA4_ID` 時整段不啟用。Firestore 才是診斷主資料來源。
7. **內容可追溯**：每個知識節點標註來源卡片 `uid` 與課本頁碼，方便日後對照與修訂。

## 節點與題目命名

- 節點 `nodeId`：用知識卡的 `uid`（例如 `abo-blood-group`），一份教材內唯一
- 題目 `questionId`：`<unit>-q<兩位數>`（例如 `blood-q01`），跨版本穩定

診斷指標（40% 探索覆蓋 ＋ 60% 首次答對率）依教材實際節點數與題數計算，
所以**節點數與題數要在教材版本內固定**；要增刪就升版本資料夾（`-v2`）。

## 課前教材必備模組

1. **核心數值速記**　翻卡，正面提問、背面答案
2. **分類樹**　點開展開下一層
3. **必背順序**　可拖曳或點選排序
4. **速查表**　例如 ABO 對照
5. **快速自測**　8～12 題，全對才 `complete()`

## 課後教材必備模組

1. **全景互動圖**　點構造看說明
2. **概念地圖**　節點與連線，呈現概念間關係
3. **主題導航＋搜尋**　全章概念可檢索
4. **機轉流程**　多步驟流程逐步展開
5. **易混淆對照**　成對比較（本產線知識卡的「容易混淆」段落直接轉用）
6. **闖關測驗**　分關、有徽章，通關才 `complete()`

## 內容來源

知識卡專案 `072026 新的專案/01_knowledge/*.md`：
- 「國考重點」→ 課前的記憶點與自測題
- 「容易混淆」→ 課後的成對比較
- 「定義／功能機轉」→ 課後的節點說明
- `figures:` 指向的圖 → 圖形題與全景圖素材

**只用已 `reviewed` 的卡片內容**。未經教師抽查的卡片可以先做開發樣板，但不可對學生發布。

## 版本與發布

1. 教材資料夾 `<unit>-<pre|post>-v<n>/index.html`
2. `npm run build` 後 `dist/materials/` 會帶出；推 `main` 由 Pages workflow 發布
3. 取得 HTTPS 網址，填入教師後台對應活動（課前活動填 pre、課後活動填 post）
4. 用「保存並預覽草稿」在桌機／平板／手機各驗一次，確認 iframe 內互動與事件回報正常
