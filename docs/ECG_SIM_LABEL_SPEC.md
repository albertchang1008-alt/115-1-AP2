## 2. 模擬器（取代目前 lab 的三段 `ecg-rate.svg`）

### 2.1 生理模型（教學近似；數值照抄，不要自行調整）
每一拍以 P 波起點為 0，全部用秒：
| 項目 | 值 |
|---|---|
| P 波 | 0.09 s（心率 >150 時 0.08），振幅 0.15 mV，半正弦 |
| PR 間隔 | 依自律神經狀態線性內插：40→0.19、75→0.16、150→0.13、200→0.12 s |
| QRS | 固定 0.09 s：Q 0–0.02 降至 −0.10 mV、R 0.02–0.05 升至 1.20、S 0.05–0.08 降至 −0.25、0.08–0.09 回基線 |
| QT | Bazett：QT＝0.40×√(前一個 R-R) |
| T 波 | 長度 min(0.16, 0.75×(QT−QRS))，振幅 0.30 mV，上升慢下降快（前 62% 走半個正弦的上升段）；T 結束＝PR＋QT |
| ST 段 | QRS 結束到 T 開始（剩餘時間） |
| 舒張期 | R-R − QT |
| 波形疊加 | 某時刻電位＝所有拍的貢獻相加（心率很快時 P 波會自然疊到前一個 T 波上，這是要呈現的現象） |
| 心率改變時機 | 只影響**下一拍**（排程下一拍時才讀心率），不可在一拍中途跳相位 |
| 呼吸性竇性心律不整（開關） | 呼吸週期 4 s；HR×(1＋0.08×v×sin(2πt/4))，v＝clamp((110−HR)/50,0,1) |
| 自律神經反應時間（開關） | 有效心率以一階追蹤目標：下降 τ＝0.8 s；上升且 <100 時 τ＝1.2 s；上升且 ≥100 時 τ＝6 s |

### 2.2 繪製與校正
- 紙速 25 mm/s、振幅 10 mm/mV **必須是真的**：小格＝0.04 s＝0.1 mV，大格＝0.20 s＝0.5 mV。畫面寬 ≥700px 顯示 6 秒，否則 2.5 秒；px/mm＝寬÷(秒數×25)。
- 方格畫在 canvas 上（背景層），不可用 CSS 背景疊在不透明 canvas 底下。
- **每個像素欄位都用模型算一次電位**（高 DPR 時每 0.5 px），不可每個 animation frame 只取一點。驗收時 R 波高度每拍必須一致。
- 依 `devicePixelRatio` 設定 canvas 尺寸；初次載入與視窗改變都要設定，改變尺寸時用模型重畫整個畫面（暫停中也不能變空白）。
- 分頁隱藏後回來（dt>0.25 s）跳過該段，不要讓時間變形。
- 1 mV 校正方波：放在畫面最左側**固定保留區**（例如左邊 8 mm 不畫波形），不可與波形重疊（試作頁的已知缺點）。
- `prefers-reduced-motion`：預設暫停，按「播放」才動。

### 2.3 控制與讀數
- 滑桿 40–200（見決策 B）＋快捷鍵 40／52／75／100／150／195；「暫停／繼續」按鈕；兩個開關（決策 C）。
- 讀數：心率、R-R、PR、QRS、QT、舒張期；下方一條「收縮（QT）／舒張」比例條。
- 生理說明依有效心率分四區，沿用試作頁內容，但**標題改成非診斷用語**（依改善計畫 P0-3）：「較慢心率區間（<60）」「安靜範圍（60–100）」「較快心率區間（>100）」「接近最大心率（≥180）」。內文保留「竇房結安靜時約 70~80 次／分（與單元一題目集一致；2026-09-24 教師決定）、此範圍的變化主要來自迷走張力」「變短的主要是舒張期」等重點，並在模擬器下方加一行「教學示意模型，不是個人心電圖判讀工具」。
- 文字替代：一個 `aria-live="polite"` 的描述區，在心率改變（節流 1 秒）與暫停時更新，例如「心率 75，R-R 0.80 秒，PR 0.16，QRS 0.09，QT 0.36，舒張期 0.44 秒」。

## 3. 暫停時的標示與卡尺

- 暫停後在監視器上：**點一下**＝選取最接近的那一拍（以 R 峰時間最近者，且該拍已畫出）；**按住拖曳**（移動 >4px）＝卡尺，顯示「x.xxx 秒＝n.n 小格」。
- 選取後監視器上只畫淡色框＋「放大 ↓」，**標示畫在下方的放大檢視**（監視器 6 秒太擠，直接標會互相遮蓋）。
- 放大檢視：仍是 25 mm/s、10 mm/mV（等比例放大，方格保持正方形），範圍含該拍與下一個 R 峰；目標約 11–22 px/mm；有「關閉」鈕；點監視器其他拍可切換。
- 三個圖層（原生 checkbox）：
  1. 波形：P（藍）、QRS（紅）、T（綠）把該段波形上色＋標籤。預設開。
  2. 間隔與段：PR 段、ST 段＝基線上的粗線；PR 間隔、QT 間隔＝波形下方量測線；R-R 間期＝R 峰上方量測線。**段與間隔必須用不同的畫法**。預設開。
  3. 機械事件（約略）：心房收縮 [P 中點, QRS 起點＋0.03]、心室收縮 [QRS 起點＋0.03, T 結束]、心室舒張 [T 結束, 下一個 QRS 起點＋0.03]。預設關，標明「約略時間」。
- 標籤不可互相遮蓋：試作頁用簡單的碰撞避讓（衝突就往下 20px 並畫引線），可沿用。
- 鍵盤：暫停時 ←／→ 切換選取的拍、Esc 關閉放大檢視；卡尺可只支援指標裝置。
- 繼續播放時清除選取、卡尺與放大檢視。

### 4.2 標示題的互動與判定
- 題目圖：每題隨機心率 60–95 的新心電圖（同 §2.1 模型、同校正方格，無校正方波），寬 ≥700px 顯示 3 秒，否則 2 秒；起點隨機落在心動週期中。只計入完整落在圖內的波段。
- 作答：在圖上拖曳框選（黃色）；另提供**鍵盤替代**：「起點」「終點」兩個 range input（步進 0.01 s），與拖曳同步。顯示「你框的範圍 x.xxx 秒＝n.n 小格」。
- 判定：對圖中所有同類波段，取起訖誤差最大值最小的那一個；起點與終點誤差都 ≤ 容許值才算對。
- 答錯回饋：
  - 若框選符合**另一種**波段（起訖都在 0.03 s 內；候選：P、PR 間隔、PR 段、QRS、ST 段、T、QT、R-R），顯示「你框的比較像『PR 段』。」＋提示。
  - 否則顯示「起點太早／太晚 n.n 小格，終點…」＋提示。
  - 錯 2 次後出現「顯示正確位置」（綠色疊在圖上）。**顯示後學生仍要自己框對才能進下一題**（維持「答對才解鎖」）。
- 答對：綠色標出正確位置，顯示學生的秒數／小格與標準答案，以及該題解析；R-R 題另顯示「60 ÷ 你量的 R-R ≈ 心率」。
- SDK：每次按「對答案」呼叫 `CourseLearning.answer(id, 是否正確)`；第一次出現提示時呼叫 `CourseLearning.hint(id)` 一次；按「顯示正確位置」也呼叫一次 `hint(id)`。不送其他新事件（決策 5）。
