# 教材圖風格指南

2026-10-13 教師定案。適用於所有新資訊圖表底圖（呼吸、泌尿、體液及之後的系統）。底圖由 ChatGPT 畫，箭頭與標籤由程式疊加。

## 一、兩層分工

| 層 | 誰做 | 風格依據 |
|---|---|---|
| 底圖（骨架） | ChatGPT | 傳統手繪醫學解剖圖譜畫風（下方第二節） |
| 箭頭、標籤、步驟編號 | 程式（標籤層，Codex 實作） | Nature 期刊式的資訊邏輯（下方第三節） |

底圖**一律不含**文字、數字、標籤、引線、圖例、箭頭、半徑線。

## 二、底圖畫風（已寫入開場指令）

- 傳統手繪醫學解剖圖譜風格：不透明水彩（gouache）或水彩的手繪質感，霧面；不要電腦 3D 渲染或亮面反光。
- 寫實但經過整理：構造邊界清楚、層次分明，必要時剖開或掀開組織呈現內部。
- 光源統一來自左上方，柔和明暗表現立體感；背景純白或極淡灰白。
- 配色採解剖圖譜慣例：動脈紅、靜脈藍、神經黃、淋巴綠、骨頭米白；**肺循環例外：肺動脈藍、肺靜脈紅**。色彩自然、不過度飽和。
- **單一尺度**：器官層級的圖不畫肺泡、細胞等顯微構造；需要時另用放大框。
- prompt 不寫特定畫家或圖譜名稱，只描述畫風；不得要求複製任何既有圖譜的圖。
- 範例：`materials-src/figures/raster/lungs-pleura/incoming/IMG-lungs-pleura-04.png`（肺葉與肺裂，定案範例）。

## 三、箭頭文法（全系列共用）

配色採色盲友善配色（Wong, Nature Methods 2011）；文字一律黑色，不用彩色字。

| 意義 | 畫法 | 顏色 |
|---|---|---|
| 物質移動：O₂ | 實心粗箭頭 | 朱橙 `#D55E00` |
| 物質移動：CO₂ | 實心粗箭頭 | 藍 `#0072B2` |
| 物質移動：其他（水、離子、尿液、血流） | 實心粗箭頭 | 由各單元另定，避免紅綠並用 |
| 調節／訊號（神經、激素） | 細虛線箭頭 | 深灰 `#444444` |
| 抑制 | 虛線＋T 形端（⊣） | 深灰 |
| 程度大小 | 線條粗細，三級 | 同上 |
| 步驟順序 | ①②③ 白底黑框編號圓點，放在箭頭起點；圖下附同號說明 | 黑 |

- 閱讀順序由上而下、由左而右；起點放左上。
- 一圖一主訊息，箭頭約 5–7 支以內；起訖點落在構造邊緣；箭頭外圍加白邊以便壓在底圖上仍清楚。

## 四、標籤

- 標籤放在底圖外側欄或留白處，引線末端以圓點對準構造。
- 手機 390 px 寬時圖內字 ≥12 px；1280 px ≥13 px。
- 重點標示：**教師 10/14 定案 A 紅色粗體**（`FOCUS_STYLE='red'`）。文字一律黑色的原則，紅色粗體重點標籤除外。

## 五、流程

1. 開場指令與每段 prompt 已含本畫風與「不畫箭頭」規則（`docs/CHATGPT_PROMPT_PACK_UNIQUE_2026-10-13.md`）。
2. 以作圖助手產圖 → Claude 審解剖與畫風 → Codex 依第三、四節做標籤層 → Claude 驗收 → 教師看畫面。
3. 新指令包格式見 `docs/CHATGPT_PROMPT_PACK_FORMAT.md`。

## 標籤呈現方式（教師 2026-10-15 裁定）

- **桌機（≥ 768px）**：中文標籤直接標在引線旁（同肺與胸膜、呼吸道）。不使用「編號＋對照表」。
- **手機（< 768px）**：圖片全寬；在錨點旁放編號圓圈，圖下附對照表。紅色粗體重點同樣套用在對照表上。
- 如果圖上已經有步驟編號 ①②③（流程步驟），手機版的標籤就改用 A、B、C…，同一張圖裡不可以出現重複的編號。
- 標籤文字的拆詞、單字成行，以及數值與單位分行，在兩種版面都禁止。
