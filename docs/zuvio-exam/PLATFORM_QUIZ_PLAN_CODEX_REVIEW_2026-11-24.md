## 二、每人打亂後的批改、分析與保密

**PASS｜用題目與選項原始 ID。** 每人開始時由伺服器建立並凍結一份排列，重送、重整和跨裝置續答沿用同一份。選答用原始 `questionId → optionId` 或由後端按該份排列還原，逐題驗證選項屬於該題。空白沿用 `''`，配分和正解讀釘住的題庫版本。`examReport`、`compareSittings`、`analyzeExam`、`researchCsv` 都以題目／選項 ID 運算。同一誘答在不同人畫面出現在不同位置，仍算同一個誘答。報表的題號與 A/B/C 依考卷基準順序，個人成績公布後的回顧則依本人順序。合成兩份排列的檢查已驗證前者。證據為 `shared/zuvio.ts:240–285`、`shared/zuvioExt.ts:194–259,931–974`。

**請教師決定依賴順序的選項。** 既有 `optionOrderFor` 遇到指涉選項前後位置的字樣會保序。直接全洗可能改變題意，ID 雖然仍可比對，計分效度會受影響。建議送教師選擇平台卷排除這類題，或明定例外保序，並在出題時提示。教材題目文字不必出現在驗收輸出。保留原有圖片及正式測驗題排除、版本缺件阻擋與後續保留題保護。若先開放後遇到題目被改列保護題，建議定義當下如何處理而不臨時發不同卷。證據為 `shared/zuvio.ts:17–41`、`functions/src/zuvioExams.ts:69–120,175–184`。

**阻擋｜先確認「公布後才看得到」的範圍。** 作答小考的學生 DTO 須明確投影題幹、選項等作答欄位，答題中與交卷後未公布時均不送正解、解析、分數或對錯訊號，並拒絕跨班、跨場或讀他人資料。正式測驗 DTO 有可沿用的白名單作法。另一方面，Zuvio 出題來源是已發布練習題，1.16.0 的 `publishBank` 將完整題目存入 chunk，而學生 `getBank` 可讀班級可見的練習題內容，包含原有答案。若教師裁定涵蓋「開考前後均不能透過既有練習看這批題的答案」，單用新 DTO 無法達成。請教師確認練習題可見性、隔離方式與公布時點。同一場公布後再開同卷補考，或同卷有後續場次，也有相同的答案可見時序問題。建議在已知補考收齊前鎖住公布，另一場已公布時能否再開同卷由教師決定。證據為 `functions/src/index.ts:470–501,599–620`、`functions/src/assessments.ts:86–128,258–288`、`shared/assessment.ts:4–11`。

## 三、計時、關場與同場補考

**阻擋｜補伺服器的狀態與競態契約。** 裁定給定預設題數×30 秒、開放前可改、開放中全場可延長。建議分別記錄主場／補考輪次、伺服器開始時刻、凍結的基本限時、全場延長與控制版號。以同一權威資料決定目前可收答與截止時間，監看與學生倒數都採伺服器時間基準。延長宜在控制文件上原子變更，避免逐人改截止發生部分成功。必須請教師確認尚未開始者遇上延長得到的時長、主場最晚允許開始的時間，以及一人已到原截止但後端還未完成寫入時，延長是否可生效。建議以伺服器已到期為準，避免是否先被背景工作掃到決定待遇。補考各人取得完整基本限時，關場與開始資格要有明確優先順序。證據為 `functions/src/assessments.ts:77–85,224–291,294–363,419–436`。

- **開始／存答／交卷／逾時**：首頁探查保持唯讀，明確開始才建立 session 及起算。存答與交卷在同一 session 內原子檢查輪次、版本、場次控制及伺服器時間。舊重送不能蓋新答案。明確最後一題仍在傳輸時交卷如何處理，例如交卷原子提交最新答案，或等已有存答的確認再交卷。關場和存答並行時以同一權威狀態判決，超時背景工作執行前重讀現行期限，避免延長成功後仍按舊期限收卷。已交卷、已逾時自動交卷的結果須可冪等重讀。
- **關場／補考／公布**：建議先原子關閉新進入與存答，再對已開始者補批最後存檔，持續到結果集合完整後發布代次。批改中與已結算應可區分，重試可續跑。教師勾選只對該場仍屬缺考且在適用名冊的學生有效。補考以同一 `sittingId` 及獨立輪次或授權識別管理，用同一授權重送只取得既有 session，上一輪的舊請求不得寫到新輪。同步處理同班兩場同時開放的發現歧義，建議以班級的目前場次指標作互斥或請教師核可多場選擇。
- **自動收卷**：要涵蓋學生離線、關頁或教師沒開監看。現行正式測驗有每分鐘排程及請求時的逾時補收，照抄只會保證寫答判定，無法保證監看在倒數歸零時立即呈現已批改。請定義結算延遲、何時在三欄狀態中顯示已完成，以及掉失的逾時工作如何補跑。測試應含門檻前後、延長／關場同時送達、雙教師雙按、學生雙分頁、54 人同時交卷、部分批改失敗重送，以及正考成績在補考前後逐列核對。

## 四、即時摘要、停止輪詢與分布

**阻擋｜平均低頻無法排除同文件熱點。** 54 人各有開始、交卷與 3 組離開／回來，對摘要是 `54 + 54 + 324 = 432` 次更新，10 分鐘平均 0.72 次／秒。若全班在 1 秒內開始，摘要同一秒有 54 筆更新意圖，連同 session 是 108 筆文件寫入意圖。整班同時到時也可能再有 54 筆摘要更新。交易會排隊、重試或失敗，提交速率要實測。Firestore 官方沒有通用的單文件 1 次／秒硬限，瓶頸隨共用文件的競爭、索引及工作量而變。建議教師核可前保留「每次輪詢讀一份」目標，採每人獨立事件／狀態，再由可重試的合併流程按節奏寫有界摘要。也可提請教師評估固定分片，代價是每次輪詢多讀數份。任一方案要定義摘要的新鮮度、收尾及故障補算，作答成功不得因教師摘要暫時未更新而重複建 session。壓測記錄 P95／P99、交易重試、失敗數、摘要延遲與對帳結果。仿真先驗證行為，實際熱點與延遲由獲核准的隔離環境量測。[Firestore 最佳做法](https://firebase.google.com/docs/firestore/best-practices) · [交易競爭](https://firebase.google.com/docs/firestore/transaction-data-contention)

**需修正｜監看資料要可重建且有界。** 以凍結的啟用名冊為三狀態分母，所有班級／篩班均驗證三欄合計、是否補考及延長後倒數。遮名建議預設開啟，同步遮住離開列表、個人篩選與無障礙標籤。現有 `src/leaveTracker.ts:3–52` 將 blur／hidden 合成一段，回來才提供累計數，`functions/src/answerIntegrity.ts:51–101` 是練習累計入庫。即時列表須增加進出兩種事件、輪次與去重鍵，明定重送、回來先於離開抵達、背景中斷、關場時仍離開的顯示方式。秒數未知時保留未知，事件僅供教師檢視，任何缺漏或回來延遲均不影響成績。避免把題目、答案、完整永久事件歷史放進摘要。以 UTF-8 和 Firestore 實際文件大小驗證 **1,048,576 bytes** 硬限，按人數上限、姓名欄長度、補考輪次和事件數算峰值。例如 54 × 512 bytes 加 162 × 256 bytes 約 67.5 KiB，仍需加文件欄名、路徑與其餘固定資料，且三次是平均假設。建議限制文件內最近事件數，既有事件可分頁保留供教師查閱，無須為分頁增加每輪固定讀量。也驗證分析及 `prep` 快照在最大題數與名冊規模能寫入。[Firestore 配額與限制](https://firebase.google.com/docs/firestore/quotas) · [Firestore 儲存空間大小計算](https://firebase.google.com/docs/firestore/storage-size)

**「關閉後零請求」驗收**：參考 `src/AttendanceAdmin.tsx:143–269` 的單一在途、可見性暫停、回前景立即刷新及清理計時器，另加小考的終止狀態。用合成場次攔截監看 callable 及相關 Firestore 請求，從關監看、跳離場次或課程、切背景、同頁結束、另一教師關場等情境各測一次。UI 關閉或本端已確認結束後，除已送出、無法撤回的請求外，不再啟動新監看請求。遠端關場時允許一個用於發現關場的終止回應，從該回應起計零。拉長在途回應，確認返回不重掛 timer。保持關閉至少 60 秒並切背景／前景，不得再發出請求或重開監聽。仍開啟的場次回前景應立即送一筆且無重疊。正常運作的其他功能、必要的後端結算與學生首頁發現應各自觀測和計費。`functions/src/attendance.ts:587–608` 的伺服器讀取方式還會讀憑證及簽到，沿用的是前端輪詢生命週期。

**分布需改用百分比**。原 `analyzeExam` 在滿分 ≤100 時計原始分，滿分 >100 才以整數百分比四捨五入後分箱。用基準程式實測滿分 80 的全對落入 `80–89`，5/51 題（約 9.80%）進入 `10–19`。平台分布應以未先四捨五入的 `得分 ÷ 滿分` 落在 `[0,10)`、`[10,20)` 至 `[90,100]`，並增加現有分析欠缺的中位數。用同一班級／全場範圍計平均、最高／最低、中位數及分布，明示分數或百分比單位。驗 0、9.99、10、89.99、90、100、配分使滿分低於／高於 100、無成績、缺考與補考併入後的人數守恆。若更動共用快取內容，須使舊快取按版本失效，並保留 Zuvio 原有輸出語意。證據為 `shared/zuvioExt.ts:127–138,168–192`、`src/ZuvioExams.tsx:457–473`。
