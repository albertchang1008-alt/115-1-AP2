# 學生端閱讀規範（2026-10-30 教師要求；所有教材與學生畫面驗收必查）

適用：平台學生端畫面、互動資訊圖表（materials）、課堂互動學生頁、複習課投影片的學生可見文字。數值為手機 390×844、平台字級「預設」時的實際顯示大小（CSS px）。

| 項目 | 下限 |
|---|---|
| 內文、解析、回饋、過關訊息 | ≥ 17px，行高 ≥ 1.6 |
| 題幹 | ≥ 18px |
| 選項、按鈕文字 | ≥ 17px；可點區域高 ≥ 44px |
| 標題 | ≥ 20px |
| 次要說明（不影響作答的註記） | ≥ 14px，且只能用於非必要資訊 |
| 圖中標籤（SVG／圖片內文字） | 實際顯示 ≥ 12px；不足時改為可放大或在圖外列文字 |
| 文字與背景對比 | ≥ 4.5:1 |

另需符合：
1. 字級跟隨平台設定：教材所有 font-size 以 `calc(Npx * var(--font-scale, 1))` 撰寫，並讀取平台的字級設定（localStorage `course-font-scale`，同網域）；切換時即時更新。
2. 平台字級「特大」（×1.3）時：無水平捲動、按鈕文字不被截斷、選項不重疊。
3. 短訊息畫面（如過關、轉場）不得讓內容只佔畫面上方一小塊：主要文字放大或垂直置中，減少大片空白。

## 驗收方式
- 自動檢查（併入 `npm run check`）：Playwright 以 390×844 與 1280×800、字級預設與特大，逐一開啟每份教材的每個畫面，量測可見文字的實際 font-size、可點區域高度、水平溢出與對比；低於下限即 FAIL，報告列出教材／畫面／元素。
- 靜態檢查：apply-kit 與 src 的 CSS 不得出現未乘 `--font-scale` 的固定 font-size（白名單需註明理由）。
- 每次交付教材或學生畫面，報告須附 390 寬手機截圖（預設＋特大各一張）與自動檢查摘要；Claude 驗收逐項核對本表。
