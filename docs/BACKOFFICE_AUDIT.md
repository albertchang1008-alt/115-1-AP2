# 後台、課程新增與多班級盤點

日期：2026-09-11。依本機原始碼檢視；不是正式環境驗收結果。
本輪已有部分修正草稿，尚未完成建置、測試或部署。以下包含尚未修復的問題與待驗證的修正。

## 一、優先處理的正確性問題

1. **草稿更動會提前改變學生存取權限。** `saveCourse` 同時寫入頂層 `classIds`，而 `bootstrap`、`access` 使用該欄位判斷學生可見課程；學生拿到的內容卻是 `published`。例如已發布給 A 班的課程，草稿改成 B 班並保存，可能使 A 班失去入口、B 班看到先前發布的內容。應區分草稿班級與發布班級，學生權限隨發布更新。
2. **學生只有全平台單一班級。** `roster/{email}` 只有 `classId`，同份名冊拒絕重複信箱／學號。支援一門課多班，不能表示同一學生在不同課程屬於不同教學分班。轉班直接更動全平台歸屬，沒有學期或課程選課關聯；歷史作答保留舊 classId，現行名冊與報表可能產生不同口徑。是否需要跨班選修／重修，須依實際授課需求決定資料模型。
3. **移除班級可能無法保存。** 課程輸入框改動 `classIds`，沒有清除該班的 `classOverrides`；後端會拒絕不屬於課程的班級設定。班級選擇元件還可能保留已移除的班級。
4. **完成度頁面與已發布課程的依據可能不同。** 教師 bootstrap 取得草稿，完成度頁以草稿的必做單元及門檻計算；學生與已發布課程的結算使用發布內容。調整草稿但尚未發布時，教師畫面和學生結果可能不同，應明確選擇並標示計算版本。
5. **跨班切換與非同步資料回傳缺乏完整隔離。** 完成度切換班級只清空 rows，沒有重設分頁游標與學生詳情；在請求未完成前切班，舊請求仍能覆寫新班畫面。切換課程的各頁面原本也保留元件狀態；課程 key 已加入修正草稿，但跨班請求隔離仍待處理。

## 二、課程新增的不便

- 新增使用瀏覽器 prompt 只詢問代碼，名稱、班級、單元、同步來源分散在不同位置；缺少完整建立表單與明確完成步驟。
- 新課程預填 `class-a`，不是教師實際班級；班級需手動記代碼並輸入逗號，沒有班級清單、多選或中文顯示名稱。全形逗號、重複代碼與無效代碼缺少即時處理。
- 原本第一個單元自動產生 UUID，與「教師自訂代碼對應 Sheet 分頁」不一致；已在修正草稿移除自動單元並補上單元代碼說明，待測試。
- 新課程尚未保存就出現在課程清單，缺少明確「未保存」提示；離開頁面、切換課程或重新整理沒有未保存編輯保護。未保存課程刪除原本呼叫後端並失敗，已加入本機移除處理，待測試。
- 課程缺少複製、封存／停用、依學期篩選。只有刪除，不適合替代學期結束後的封存。
- 單元有新增和上移，缺少刪除、下移、複製操作；輸入錯代碼後沒有方便的修正途徑。

## 三、後台與多班級缺少的操作

- 沒有獨立班級管理：班級名稱、學期、班級建立／選取、班級人數、管理教師等。
- 班級授權主要在名冊匯入時建立；課程儲存只檢查已存在的班級，沒有完成班級建立／認領流程，也沒有授權其他教師的介面。
- 各班可分別設定必做、門檻、開放及期限，這部分已具備；但需逐單元逐班輸入，缺少整批套用／複製安排。
- 教學總覽的題目統計固定讀取第一個班級，沒有切班或全部班級比較。
- 名冊可以匯入、啟用／停用，缺少搜尋、直接修正學生資料與有明確影響提示的轉班操作。
- 同步成功只更新草稿；後台缺少一眼可辨的「未保存／已保存草稿／已同步未發布／已發布」狀態。
- 題庫頁的課程參考 Sheet 連結與平台設定的同步 Sheet ID 是兩個不同欄位，容易誤認保存參考連結就會切換同步來源；已修改說明，待確認是否應合併入口。
- 原始示例 API 只保存單一課程，部分未實作方法仍回傳成功；不能用示例模式的操作結果證明正式多課程或同步流程正確。

## 四、建議整合修復順序

1. 先定義「班級」：行政班為主，或需要每課程独立教學分班；保留一門課可選多班。
2. 建立班級清單與課程完整新增表單，取消示例班級預填；新單元明確對應 Sheet 分頁。
3. 修正草稿與發布的權限、完成度版本依據、刪除班級設定及跨班畫面狀態。
4. 補上必要的單元操作、保存提示、同步狀態與課程封存流程。
5. 統一進行自動測試與真實後台／Google Sheet 驗收。

## 五、同一輪驗收情境

- 建立一門課與 A、B 兩班，新增自訂代碼單元，保存後重新登入仍保留。
- Sheet 同步兩班名冊及題庫，內容無變更不重複寫入學生文件或建立題庫版本。
- 修改／移除草稿班級，發布前不影響學生原有權限；發布後依新的班級範圍生效。
- A、B 班設定不同門檻與期限，教師預覽、学生顯示、完成度與結算使用一致的發布設定。
- 切換課程／班級時無舊題庫、舊名冊、游標或未完成請求混入。
- 未保存課程取消、單元刪除、已發布課程封存以及歷史紀錄保留符合預期。
- 名冊衝突、無權限課程、無效分頁、部分同步失敗與同步中斷後重試顯示清楚結果。
