## B. 血壓測量 `blood-pressure-measurement`（配合第 5 週實驗）

### B1 情境實驗室改互動「放氣滑桿」（kit 新 lab 元件 `bp-cuff`）
- 滑桿：壓脈帶壓力 160 → 60 mmHg（預設 150），可拖動與鍵盤調整，另有「自動放氣」播放鈕（每秒約 3 mmHg）。
- 同步呈現三塊：
  1. **壓力–時間圖**：動脈壓波形在 80–120 mmHg 間起伏（收縮期上升較陡），壓脈帶壓力為水平線隨滑桿移動；壓脈帶線低於波峰的區段標 ♪。
  2. **肱動脈剖面**：壓脈帶 >120 壓閉；80–120 只在收縮期斷續衝過（亂流漩渦）；≤80 平順通過。
  3. **聲音指示**：無聲／柯氏音（斷續）／聲音消失；並在 120 處固定標「第一聲＝收縮壓」，80 處標「聲音消失＝舒張壓」。
- 範例數值 120／80，標「示意數值」。
- **kit 修改**：目前 `lab.widget` 模式不會渲染預測題；改為 widget 模式也照常渲染 `lab.predict`（預測題內容不改）。元件不送 CourseLearning 事件。

### B2 節點圖（取代文字流程框）
| 節點 | 圖 |
|---|---|
| 01 聽診法原理 | **澆花水管比喻**三格：捏死→沒水；稍放鬆→水「噗、噗」斷續噴（＝柯氏音）；完全放開→平順。圖說：「水管只是比喻。」 |
| 02 柯氏音 | 肱動脈受壓變窄，血液斷續衝過形成亂流漩渦＋♪ |
| 03 收縮壓 | 壓力–時間圖局部：壓脈帶線第一次低於波峰處標 ♪ 與「收縮壓」 |
| 04 舒張壓 | 壓力–時間圖局部：壓脈帶線低於波谷後 ♪ 消失，標「舒張壓」 |
| 05 測量步驟 | 坐姿、手臂與心臟同高；壓脈帶綁上臂，下緣約在肘窩上方 2–3 cm；聽診器放肘窩肱動脈 |
| 06 判讀與換算 | 手臂三種高度（高於／等於／低於心臟）與讀值（偏低／正確／偏高），以血液柱高度示意；旁附 120／80 → 脈壓 40、MAP 約 93 |

## C. 微血管物質交換與組織液 `capillary-exchange`

### C1 情境實驗室主圖改「Starling 力量沿微血管變化圖」（3 狀態保留：動脈端／靜脈端／淋巴回收）
- 橫軸：微血管動脈端 → 靜脈端；縱軸：mmHg。
- 微血管靜水壓：由 35 線性降到 18；血漿膠體滲透壓：25 水平線；交點約在全長 59% 處。
- 交點前塗「淨濾出區」（向外箭頭），交點後塗「淨回收區」（向內箭頭）；註明濾出略多於回收，多出的組織液交由淋巴。
- 三狀態分別高亮動脈端（35−25＝向外 10）、靜脈端（18−25＝向內 7）、淋巴回收。數值標「示意數值（OpenStax 模型）」。

### C2 節點圖
| 節點 | 圖 |
|---|---|
| 01 擴散 | 管壁兩側濃度點：O₂、葡萄糖由血液往組織，CO₂ 反向，標「高濃度→低濃度」 |
| 02 通過管壁的途徑 | 管壁剖面三路徑：脂溶性物質穿過內皮細胞；水與小分子走細胞間隙；血漿蛋白被擋住 |
| 03 微血管靜水壓 | **拔河比喻**左半：靜水壓把液體往外推 |
| 04 血漿膠體滲透壓 | 拔河右半：白蛋白把液體往內拉 |
| 05 淨過濾 | 拔河兩格：動脈端 35 對 25 → 往外；靜脈端 18 對 25 → 往內 |
| 06 淋巴回收 | 微血管旁畫盲端淋巴微管收走多出組織液；小插圖：回收不及時組織間液體堆積＝水腫 |
圖說註明「拔河只是比喻」。

### C3 互動公式樹（重用 `factor-tree`，放重點整理表上方）
- 根：組織液量（增加過多時標「水腫」）。
- 分支（**分支對根的方向須可設定**，元件需支援 sign）：
  - 濾出（＋）：微血管靜水壓（＋）、血漿膠體滲透壓（−；白蛋白減少→膠體滲透壓↓→濾出↑）
  - 淋巴回收（−）：淋巴回流（＋）
- 互動同心輸出量：點葉節點高亮路徑、增加／減少切換、說明面板、「看相關節點」（靜水壓→03、膠體滲透壓→04、淋巴→06）、重設。
- 說明範例：「血漿白蛋白減少 → 膠體滲透壓↓ → 拉回的力量變小、濾出↑ → 組織液↑，過多時形成水腫。」

## E. 心臟II 共通
1. **顏色語意統一**（本輪新增的圖一律遵守；心電圖基礎不動）：充氧血＝紅、缺氧血＝藍、電訊號＝琥珀黃、壓力＝紫、心搏量 SV＝心輸出量規格指定的主色、增加＝綠＋↑、減少＝橙＋↓（不可只靠顏色）。
2. **教材互相參照（純文字，不做連結）**：教材在平台 iframe 內執行，跳到別份教材會讓學習紀錄記到錯的活動，所以只寫文字提示，例如「延伸：血壓測量的平均動脈壓 MAP 也用到心輸出量」。建議位置：心輸出量節點 01 ↔ 血壓測量節點 06；微血管交換節點 06 ↔ 淋巴系統；全身主要動靜脈「胃」路徑 ↔ 循環路線肝門脈；電性活動節點 9 ↔ 心電圖基礎。
3. **常見誤解提示框**（kit 新增 `misconceptions` 區塊，放重點整理表上方；手工教材同樣式手動加入）：
   - 心輸出量：「心率越快，心輸出量一定越大」✗ → 過快時舒張期縮短、充血不足，心搏量下降。／「心肌拉越長收縮越強，沒有上限」✗ → 超出生理範圍反而變弱。
   - 血壓測量：「聽到的是心跳聲（心音）」✗ → 是血液斷續衝過受壓動脈的柯氏音。／「放氣越快越準」✗ → 太快可能錯過第一聲。
   - 微血管交換：「液體在微血管只會往外流」✗ → 靜脈端會回收。／「組織液全部回到微血管」✗ → 多出的由淋巴回收。
   - 全身主要動靜脈：「主動脈弓左右兩側分支一樣」✗ → 右側先經頭臂動脈，左側直接分出左頸總、左鎖骨下。
   - 心臟電性活動：「P 波就是心房收縮」✗ → P 波是心房去極化，收縮在其後。／「房室結傳得越快越好」✗ → 延遲讓心室有時間充血。
