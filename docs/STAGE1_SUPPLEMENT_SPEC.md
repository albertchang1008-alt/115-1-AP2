### 1. 心輸出量的調節 `cardiac-output`
- 副標題：心輸出量由心率與每搏量決定；前負荷、收縮力、後負荷與自主神經共同調節。
- stats：`CO = HR × SV`／`約 5 L/min` 靜息成人（70 次/分 × 70 mL）／`SV = EDV − ESV`
- 實驗室：①交感興奮：心率↑、收縮力↑ → CO↑；②迷走（副交感）興奮：心率↓ → CO↓；③回心血量增加：EDV↑ → Frank-Starling → SV↑。
  預測：回心血量增加（生理範圍內），下一次收縮的每搏量？→ 增加。
- 節點：
  1. 心輸出量＝心率×每搏量：一側心室每分鐘射出的血量；靜息約 5 L/min；長時間左右心輸出量相等。應用：運動時可增加數倍。
  2. 每搏量＝EDV−ESV：EDV 約 120 mL、ESV 約 50 mL → SV 約 70 mL；射出分率＝SV÷EDV 約 60%。
  3. 前負荷與 Frank-Starling 定律：前負荷＝收縮前心室被血液撐開的程度（EDV）；生理範圍內心肌被拉長越多，收縮越強，SV↑；使左右心輸出量保持平衡。
  4. 收縮力：相同前負荷下，心臟交感神經的節後神經末梢釋放正腎上腺素（NE），使收縮力增強 → SV↑、ESV↓。腎上腺髓質另外把腎上腺素釋放到血液，隨循環到達心臟，也可增強收縮力；這是內分泌作用，須與神經末梢的傳導物質分開。
  5. 後負荷：心室射血必須克服的動脈壓力；後負荷↑時 SV 傾向↓。
  6. 自主神經與心率：心臟交感神經的節後神經末梢釋放正腎上腺素（NE），使心率↑；迷走神經所屬的副交感節後神經末梢釋放乙醯膽鹼（ACh），使心率↓。安靜時迷走作用較強，心率低於竇房結自身頻率。應用：心率過快時舒張期縮短、心室充血時間減少。
- 先備：①CO＝？心率×每搏量／心率＋每搏量／每搏量÷心率／血壓×阻力 ②EDV 120、ESV 50 mL，SV？70／170／50／120 mL ③生理範圍內前負荷增加，收縮力？增強／減弱／不變／停止 ④交感對心臟？心率與收縮力增加／心率下降／只作用於血管／使心臟停止 ⑤迷走神經對心臟？降低心率／增加收縮力／增加心率／增加後負荷 ⑥後負荷指？心室射血要克服的動脈壓力／舒張末期容積／心房壓力／心率
- 情境：①【生活情境】慢跑時心率 70→140、SV 70→100 mL，CO 約？14 L/min／9.8 L/min／7 L/min／4.9 L/min ②【模型觀察】平躺抬腿使回心血量增加，下一次 SV？增加／減少／不變／變為零 ③【生理判讀】交感作用使收縮力增強，ESV？減少／增加／不變／等於 EDV ④【生理判讀】主動脈壓升高、其他不變，SV？減少／增加／不變／加倍 ⑤【模型觀察】心率極快時心室充血時間？減少，EDV 可能下降／增加／不變／與心率無關
- 出處：OpenStax A&P 2e 19.4 Cardiac Physiology。

### 2. 血壓測量 `blood-pressure-measurement`（配合第 5 週實驗）
- 副標題：用壓脈帶與聽診器，從柯氏音的出現與消失讀出收縮壓與舒張壓。
- stats：`柯氏音` 斷續血流的聲音／`第一聲＝收縮壓`／`消失＝舒張壓`
- 實驗室（肱動脈剖面＋壓力條）：①壓脈帶壓力＞收縮壓：動脈被壓閉、無血流、無聲；②介於兩者之間：只在收縮期衝過、斷續亂流 → 柯氏音；③＜舒張壓：血流恢復平順、聲音消失。
  預測：放氣時聽到的第一個規律聲音代表？→ 收縮壓。
- 節點：
  1. 聽診法原理：壓脈帶加壓阻斷肱動脈血流，再緩慢放氣，聽血流恢復的聲音。
  2. 柯氏音：血液斷續衝過被壓窄的動脈形成亂流所產生。
  3. 收縮壓：第一個規律柯氏音出現時的壓力。
  4. 舒張壓：柯氏音消失時的壓力。
  5. 測量步驟：坐姿休息、手臂與心臟同高、壓脈帶寬度合適、聽診器放肘窩肱動脈；先加壓到橈動脈摸不到再加約 30 mmHg；每秒約 2–3 mmHg 放氣。
  6. 判讀與換算：120／80 → 脈壓 40、MAP≈80＋40÷3≈93 mmHg（連結血液動力學）；手臂高於心臟讀值偏低、低於心臟偏高。
- 先備：①聽診法常量？肱動脈／橈動脈／頸動脈／股動脈 ②柯氏音來自？血液斷續通過受壓動脈的亂流／瓣膜關閉／呼吸聲／壓脈帶漏氣 ③第一個柯氏音＝？收縮壓／舒張壓／脈壓／平均動脈壓 ④柯氏音消失＝？舒張壓／收縮壓／脈壓／心率 ⑤手臂位置？與心臟同高／高於頭部／垂到地面／任意 ⑥血壓 120/80 mmHg 的脈壓？40／80／120／200 mmHg
- 情境：①【實驗觀察】加壓到 150 無聲，放氣到 118 開始聽到規律聲，76 消失，記錄為？「118/76 mmHg」／「150/76 mmHg」／「118/150 mmHg」／「76/118 mmHg」 ②【實驗觀察】壓力介於收縮壓與舒張壓之間，肱動脈血流？只在收縮期斷續衝過／完全停止／完全平順／倒流 ③【實驗觀察】手臂舉得比心臟高，讀值？偏低／偏高／不變／無法測量 ④【實驗觀察】放氣太快可能？錯過第一聲而判讀不準／讓血壓真的升高／聽到心音／壓脈帶破裂 ⑤【模型觀察】量得 120/80 mmHg，MAP 約？93／100／80／200 mmHg
- 出處：OpenStax A&P 2e 20.2；本課血壓測量實驗講義。

### 3. 微血管物質交換與組織液 `capillary-exchange`
- 副標題：擴散完成大部分交換；靜水壓與膠體滲透壓的拉鋸決定液體濾出或回收，多出的組織液交給淋巴。
- stats：`擴散` 最主要交換方式／`動脈端濾出、靜脈端回收`／`多出的組織液 → 淋巴`
- 實驗室（OpenStax 模型數字）：①動脈端：靜水壓 35＞膠體滲透壓 25 mmHg → 淨濾出 10；②靜脈端：靜水壓 18＜25 → 淨回收 7；③淋巴回收：濾出略多於回收，多出的組織液與少量蛋白質由淋巴微管帶走。
  預測：微血管動脈端液體淨移動方向？→ 由血管往組織間隙。
- 節點：
  1. 擴散：O₂、CO₂、葡萄糖等順濃度梯度通過管壁，是最主要的交換方式。
  2. 通過管壁的途徑：脂溶性物質穿過內皮細胞；水與小分子經細胞間隙；大分子如血漿蛋白不易通過。
  3. 微血管靜水壓：血壓把液體推出血管。
  4. 血漿膠體滲透壓：主要由白蛋白形成，把液體拉回血管。
  5. 淨過濾：動脈端淨濾出、靜脈端淨回收（模型數字同實驗室）。
  6. 淋巴回收：濾出略多於回收，多出的組織液由淋巴送回靜脈；生成多於回收時組織間液體堆積（⚠️「水腫」一詞是否保留，請教師決定）。
- 先備：①最主要交換方式？擴散／主動運輸／胞吞／過濾 ②推出液體的力？微血管靜水壓／膠體滲透壓／淋巴壓／大氣壓 ③拉回液體的力？血漿膠體滲透壓／微血管靜水壓／心臟收縮／重力 ④膠體滲透壓主要來自？白蛋白／葡萄糖／紅血球／鈉離子 ⑤動脈端淨移動？濾出到組織間隙／回收入血管／不移動／進入淋巴結 ⑥多出的組織液由何回收？淋巴管／動脈／肺泡／腎小管
- 情境：①【模型觀察】動脈端靜水壓 35、膠體滲透壓 25，淨過濾壓？向外 10／向內 10／向外 60／0 mmHg ②【模型觀察】靜脈端靜水壓 18、膠體滲透壓 25，液體？淨回收／淨濾出／不移動／全部進淋巴 ③【生理判讀】血漿白蛋白減少，回收入血管的液體？減少，組織液增加／增加／不變／全部回收 ④【生活情境】久站時下肢微血管靜水壓升高，組織液生成？增加／減少／不變／停止 ⑤【生活情境】運動時肌肉產生較多 CO₂，主要以何方式進入微血管？擴散／胞吞／過濾／主動運輸
- 出處：OpenStax A&P 2e 20.3 Capillary Exchange。

### 4. 全身主要動脈與靜脈 `major-vessels`
- 副標題：從主動脈弓出發追蹤頭頸、上肢、腹部、下肢的主要血管，再沿上、下腔靜脈回到右心房。
- stats：`3 條` 主動脈弓分支／`成對` 腎動脈／`最長` 大隱靜脈
- 實驗室（人體正面血管路徑圖，圖左＝人體右）：①頭頸與上肢；②腹部器官；③下肢。
  預測：左手臂的血液由主動脈弓哪一分支出發？→ 左鎖骨下動脈。
- 節點：
  1. 主動脈的分段：升主動脈 → 主動脈弓 → 胸主動脈 → 腹主動脈 → 約第 4 腰椎分為左右髂總動脈。
  2. 主動脈弓三分支：頭臂動脈（再分右頸總、右鎖骨下）、左頸總動脈、左鎖骨下動脈。
  3. 上肢動脈：鎖骨下 → 腋 → 肱 → 橈、尺動脈；量血壓用肱動脈、手腕摸脈搏用橈動脈。
  4. 腹主動脈分支：不成對的腹腔幹（胃、肝、脾）、上腸繫膜、下腸繫膜動脈；成對的腎動脈。
  5. 下肢動脈：髂總 → 髂外 → 股 → 膕 → 脛前、脛後；足背可摸到足背動脈。
  6. 主要靜脈：上腔靜脈收集頭頸與上肢（左右頭臂靜脈匯合）；下腔靜脈收集下肢與腹部；淺層靜脈：頭靜脈、貴要靜脈、肘正中靜脈（抽血常用）、大隱靜脈（人體最長靜脈）。

### 5. 血型與輸血 `blood-types`
- 副標題：紅血球表面抗原決定血型，血漿抗體遇到對應抗原會凝集；輸血與血型鑑定都依這個原理。
- stats：`4 型` ABO 血型／`D 抗原` 決定 Rh／`凝集` 抗原遇對應抗體
- 實驗室（血型鑑定玻片，抗 A／抗 B／抗 D 三格）：①A 型 Rh＋；②O 型 Rh＋；③AB 型 Rh−（顯示各格凝集與否）。
  預測：抗 A 凝集、抗 B 不凝集，ABO 血型是？→ A 型。
- 節點：
  1. 血型由紅血球表面抗原（凝集原）決定。
  2. ABO 系統：A 型有 A 抗原、抗 B 抗體；B 型有 B 抗原、抗 A 抗體；AB 型兩種抗原、無抗體；O 型無抗原、抗 A 與抗 B 抗體。
  3. 凝集反應：抗原遇對應抗體，紅血球黏聚，進而破壞。
  4. Rh 系統：有 D 抗原為 Rh 陽性；Rh 陰性者通常不會天生帶抗 D 抗體，接觸 Rh 陽性血後才產生。
  5. 輸血原則：以同型輸血為原則；關鍵是輸入的紅血球抗原不可遇到受血者血漿中的對應抗體；O 型紅血球無 A、B 抗原，傳統稱「萬能捐血者」，AB 型稱「萬能受血者」（⚠️ 此傳統用語是否保留，請教師決定）。
  6. 血型鑑定：分別加入抗 A、抗 B、抗 D 血清，看是否凝集。
- 先備：①血型由何決定？紅血球表面抗原／白血球數目／血漿顏色／血小板形狀 ②A 型血漿中的抗體？抗 B／抗 A／抗 A 與抗 B／無 ③O 型紅血球的抗原？無 A 也無 B／只有 A／只有 B／A 與 B ④AB 型血漿中的抗體？無／抗 A／抗 B／抗 A 與抗 B ⑤Rh 陽性指？有 D 抗原／有抗 D 抗體／無 D 抗原／有 A 抗原 ⑥凝集反應是？抗原與對應抗體結合使紅血球聚集／血小板形成血栓／紅血球攜帶氧氣／白血球吞噬細菌
- 情境：①【實驗觀察】抗 A 凝集、抗 B 不凝集，ABO 血型？A／B／AB／O ②【實驗觀察】抗 A、抗 B 都不凝集？O／A／B／AB ③【模型觀察】B 型受血者輸入 A 型紅血球會？受血者的抗 A 抗體使輸入紅血球凝集／完全沒有反應／受血者變成 A 型／輸入的血漿使受血者紅血球增加 ④【模型觀察】Rh 陰性者第一次接觸 Rh 陽性血，抗 D 抗體？接觸後才逐漸產生／出生就大量存在／永遠不會產生／會轉成 Rh 陽性 ⑤【生理判讀】O 型紅血球傳統稱萬能捐血者，原因？紅血球上沒有 A 與 B 抗原／血漿中沒有抗體／含最多血紅素／不含 D 抗原
- 出處：OpenStax A&P 2e 18.6 Blood Typing。不放新生兒溶血等疾病內容。

### 6. 淋巴器官 `lymphoid-organs`
- 副標題：骨髓與胸腺讓淋巴球誕生與成熟；淋巴結、脾臟、扁桃腺與黏膜淋巴組織是遇見抗原、啟動防禦的地方。
- stats：`初級` 骨髓、胸腺／`最大` 脾臟／`血液 vs 淋巴` 脾臟與淋巴結過濾對象不同
- 實驗室（人體正面淋巴器官定位圖）：①初級淋巴器官（骨髓、胸腺）；②次級淋巴器官（淋巴結、脾臟、扁桃腺）；③黏膜相關淋巴組織（扁桃腺、培氏斑、闌尾）。
  預測：T 淋巴球在哪個器官成熟？→ 胸腺。
- 節點：
  1. 初級與次級：初級（骨髓、胸腺）負責淋巴球生成與成熟；次級（淋巴結、脾臟、扁桃腺、黏膜淋巴組織）負責遇見抗原並活化。
  2. 胸腺：位於胸骨後方、縱膈前上部；T 細胞在此成熟；青春期後逐漸退化，被脂肪組織取代。
  3. 脾臟：位於左上腹，是最大的淋巴器官；白髓富含淋巴球、參與免疫；紅髓過濾血液、清除老舊紅血球。
  4. 淋巴結構造：被膜下為皮質（B 細胞濾泡）、副皮質（T 細胞）、髓質；多條輸入淋巴管進入，輸出淋巴管由門部離開。
  5. 扁桃腺：咽扁桃腺、腭扁桃腺、舌扁桃腺環繞咽部，形成入口防線。
  6. 黏膜相關淋巴組織：散布在消化道、呼吸道黏膜，如小腸迴腸的培氏斑、闌尾。
- 先備：①初級淋巴器官是？骨髓與胸腺／淋巴結與脾臟／扁桃腺與闌尾／肝臟與腎臟 ②T 細胞在何處成熟？胸腺／脾臟／淋巴結／扁桃腺 ③人體最大的淋巴器官？脾臟／胸腺／淋巴結／扁桃腺 ④脾臟清除老舊紅血球主要在？紅髓／白髓／皮質／副皮質 ⑤腭扁桃腺位於？口咽兩側／胸骨後方／左上腹／腋窩 ⑥培氏斑位於？小腸迴腸黏膜／胃壁／肝臟／氣管
- 情境：①【模型觀察】脾臟與淋巴結的過濾對象？脾臟過濾血液，淋巴結過濾淋巴／兩者都過濾淋巴／兩者都過濾尿液／脾臟過濾淋巴，淋巴結過濾血液 ②【生理判讀】成年後胸腺的變化？逐漸退化並被脂肪取代／持續變大／變成脾臟／停止所有功能並消失 ③【模型觀察】經口鼻進入的病原，最先遇到咽部哪一圈淋巴組織？扁桃腺／脾臟／胸腺／骨髓 ④【模型觀察】脾臟白髓的主要功能？淋巴球參與免疫反應／儲存膽汁／製造尿液／分泌胰島素 ⑤【生理判讀】小腸黏膜的培氏斑屬於？黏膜相關淋巴組織（次級淋巴器官）／初級淋巴器官／內分泌腺／消化腺
- 出處：OpenStax A&P 2e 21.1。
